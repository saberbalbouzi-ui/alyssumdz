## مطابقة الوحدات مع ما نملكه اليوم (ملاحظات لنا)

| الوحدة | الحالة في مشروعنا |
|---|---|
| Dashboard | قائم جزئياً (إحصاءات + مشاهدون الآن)؛ التصميم الجديد في `docs/dashboard-design-reference.md` |
| Products / Collections | قائم (المنتجات، التصنيفات، السمات `attributes`، المجموعات) |
| Inventory | قائم جزئياً (المخزون والأرباح)؛ لا Locations متعددة بعد |
| Orders / Fulfillment / Tracking | قائم (الطلبات، الطلبات المسجلة مع شركات التوصيل، تحديث حالات الشحن) |
| Returns / Refunds | غير قائم |
| Customers / Segments | قائم جزئياً (إعادة الشراء، القائمة السوداء، الولاء، حسابات الزبائن) |
| Online Store (Theme/Pages/Navigation) | **قوّتنا:** مطوّر الصفحات + نسخ القالب + هيدر/فوتر الموقع + عناوين الموقع؛ يُعامَل كوحدة رئيسية |
| Discounts | قائم جزئياً (الكوبونات) |
| Marketing | قائم جزئياً (رسائل واتساب لإعادة الشراء) |
| Analytics / Reports | قائم جزئياً (التحليلات) |
| Shipping / Payments | قائم جزئياً (رسوم الولايات، شركات التوصيل، الدفع عند الاستلام) |
| Files / Media | قائم (مكتبة الصور + تنظيف الصور) |
| Search (Ctrl+K) | غير قائم — مقترح في مخطط التصميم |
| Productivity (bulk, CSV, saved views, shortcuts) | جزئي (تصدير CSV/Sheets، اختصارات المحرّر) |
| Automation (Flow) | غير قائم |
| Apps / Extensions | غير قائم (فكرة `PB.WIDGETS` أساس محتمل) |
| AI / Sidekick | «اسألني» (مساعد اللوحة) + وكيل المتجر الذكي؛ أدوات Gemini معطّلة بقرار صاحب المتجر |
| Staff & Permissions | غير قائم (يحتاج `store_id` + أدوار في Supabase) |
| Sales Channels / POS / International / Finance | غير قائم (مرحلة توسّع) |

## ترتيب مقترح (من تقرير التاجر)
1. **أساسية:** Dashboard، Products، Orders، Customers، Inventory، Store/Website، Pages (+Page Builder كوحدة رئيسية)، Media، Settings.
2. **مهمة:** Discounts، Marketing، Analytics، Shipping، Payments، Returns.
3. **توسّع:** Automation، Apps، Sales Channels، POS، AI Assistant، International، Finance، Staff & Permissions.
