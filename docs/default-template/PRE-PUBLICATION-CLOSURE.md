## 3) كيف يُحَلّ مسار المتجر

لا مسار متجر مُخزَّن ولا اسم مجلد: كل صفحة تُصيَّر وفق موقعها من جذر المتجر عبر `ctx.base` الموجود أصلاً في المنصة:

- الرئيسية، `shop.html`، `cart.html`، `account.html` (تُبنى من HTML الرئيسية): `base = ""`.
- صفحات `/lp/<slug>/` وصفحات المنتج `p/<slug>/`: `base = "../../"`.

الهيدر `shdr` كان يستعمله أصلاً؛ أما `sfoot` فكان يطبع الرابط كما كُتب. صار `sfoot` يطبع `base + الرابط` للروابط النسبية، فيكتب المولّد `shop.html` فقط ويصير `shop.html` أو `../../shop.html` بحسب مكان الصفحة، فيصلح التثبيت في `/` أو `/store/` أو `/a/b/store/` بلا أي افتراض. الروابط المطلقة (`https:` و`mailto:` و`tel:` و`#` و`/...`) لا تُمسّ. جرى فحص مصادر القوالب الأخرى: كل روابط فوترها النسبية الموجودة (`index.html#...`) تستفيد من الإصلاح نفسه ولا تتضرر.

## 4) نتائج اختبار الروابط (جذر ومجلد فرعي)

**G9** — 189 فحصاً، 0 إخفاق، محلياً وفي CI. لكل مجال من الخمسة (`s-nexus` و`-fashion` و`-beauty` و`-tech` و`-food`) يُثبَّت القالب وتُنشر الرئيسية (فتُولَّد shop/cart/account) وصفحة منتج وصفحتا `/lp/` (`nx-faq` و`nx-collection`)، ثم على **الجذر `/`** و**`/store/`** معاً، لكل من الصفحات السبع (الرئيسية، المتجر، السلة، حسابي، المنتج، `/lp/nx-faq/`، `/lp/nx-collection/`):

1. روابط الفوتر الأربعة (الرئيسية/المتجر/السلة/حسابي) تُحَلّ تماماً إلى `origin + المسار + /index|shop|cart|account.html` ولا يبقى رابط يبدأ بـ`/`.
2. كل رابط داخلي في الصفحة (حتى ~48) يُجلَب بلا 4xx؛ لا صور مكسورة، لا استجابات 4xx للموارد (خطوط/CSS/JS/صور)، لا أخطاء JS.
3. نقرة حقيقية على «المتجر» و«السلة» تصل إلى `shop.html`/`cart.html` داخل المسار نفسه (كل صفحات `s-nexus`، والرئيسية للباقي؛ نافذة دخول «حسابي» تُغلق بزرها كما يفعل الزائر).
