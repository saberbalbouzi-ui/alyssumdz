# خارطة طريق Alyssum Theme Studio (المراحل B–F)

المرجع: `docs/THEMES-AUDIT.md` · الفرع: `feature/alyssum-theme-studio`

## مبادئ معمارية ملزمة (مستمدة من قواعد التكليف)

1. مصدر القوالب = مولدات Python فقط؛ لا تعديل يدوي لأي JSON مولّد.
2. لا كسر لمعمارية Page Builder ولا لتدفقات الطلب/الدفع/التوصيل.
3. صفحات القالب الجديدة تُبنى من عناصر PB الحقيقية (heading/products/shopcats/html…)، لا محاكاة معزولة.
4. البيانات التجريبية تبقى موسومة `demo` وتُستبدل ببيانات المتجر عند النشر (السلوك الحالي يُحترم ويُعمَّم).
5. RTL/العربية أولاً، مع بقاء الإنجليزية/الفرنسية تعمل كما اليوم.

## المرحلة B — إصلاح وتحسين القوالب الموجودة (17)

| # | الإجراء | النطاق | معيار القبول |
|---|---|---|---|
| B1 | إلغاء تكرار الصور داخل منتجات كل قالب (7 قوالب) | gen-templates-copy.py `dp` | لا صورة مكررة في أي قائمة dp |
| B2 | تصحيح صور الفئات غير المتوافقة (s-fashion مبادلة، s-marketplace) | copy.py `dc` + niche.py `cats(imgs=)` | كل صورة فئة تعبّر عن اسمها |
| B3 | تقليل تقاطع الصور بين القوالب المتجاورة (aurora/tech/it، fresh/herbs/honey، pop/fashion) بإضافة صور جديدة مراجعة | fetch-template-images.py + packs | لا صورة منتجات في >2 قالبين |
| B4 | تخفيف التشابه البنيوي: تنويع ترتيب/بنية الأقسام الختامية بين القوالب (كسر احتكار tail) | niche.py | ≤4 قوالب تتشارك البنية نفسها بالكامل |
| B5 | إعادة توليد المصغرات لكل القوالب المعدّلة | gen-template-thumbs.js | لقطات جديدة محدثة |

## المرحلة C — الدفعة الأولى من القوالب الجديدة (أولوية تجارية)

ستة قوالب، كل واحد بهوية مستقلة (اسم تجاري، لوحة، خط، بنية أقسام مختلفة، صور خاصة، نصوص خاصة، prod-skin):

| القالب | الميدان | الاسم التجاري | الاتجاه التصميمي |
|---|---|---|---|
| s-perfume | عطور | «عبق» — Maison Oud | داكن فاخر، عنبر وعود، زجاج، سرد عطري بالتمرير |
| s-skincare | عناية فاخرة | «لوميير» | عيادات نظيفة، أبيض مضيء، قبل/بعد، مكوّنات علمية |
| s-makeup | مكياج | «روج ستوديو» | إديتوريال جريء، شبكة غير متماثلة، درجات ألوان |
| s-women | أزياء نسائية | «أتيليه نوا» | إديتوريال أزياء، lookbook، خطوط رفيعة |
| s-men | أزياء رجالية | «غرين» | tailoring داكن، شبكة سويسرية، تفاصيل خام |
| s-kids | أطفال وألعاب | «بوبون» | مرح دائري، ألوان حلوى، بطاقات ملصقات |

كل قالب: ملف JSON مولّد + prod-skin + مصغّرات + دخول shared-files + اجتياز اختبار القبول.

## المرحلة E — مكتبة المعاينة والتثبيت

- E1: توسيع TplSite بصفحات تعريفية للقالب (من نحن، اتصل بنا، FAQ، الشحن والإرجاع، الخصوصية، الشروط) تُبنى من هوية القالب وتُعرض في المعاينة الكاملة، وتُستبدل بروابط صفحات المتجر الحقيقية عند النشر.
- E2: مفتاح Desktop/Mobile داخل نافذة المعاينة الكاملة (موجود جزئياً في SitePreview — يُعمَّم).
- E3: بطاقة القالب تعرض قائمة الصفحات المتضمنة والمميزات (من حقول index.json الجديدة `pages`/`features`).
- E4: تثبيت اختياري للصفحات التعريفية مع القالب (اختياري، لا يمس بيانات المتجر، قابل للتراجع).

- F2: لقطات Desktop+Mobile لكل قالب جديد ومعدّل (Playwright) ومراجعة بصرية.

- F4: تحديث THEMES-IMPLEMENTATION.md بما أُنجز وما تبقى والعيوب المعروفة.
