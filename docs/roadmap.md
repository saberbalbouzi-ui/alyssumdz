# خارطة طريق المنصة (على شاكلة Shopify) — مبنية على `docs/shopify-admin-modules.md`

المبدأ: كل أداة جديدة يجب أن تعمل على **الأنظمة الثلاثة** دون تغيير: (1) GitHub Pages + Apps Script/Supabase، (2) نسخة PHP للمواقع المنفردة (`CONFIG.BACKEND="php"`)، (3) الوضع المحلي. لذلك نبدأ بما هو **واجهة فقط** أو يُخزَّن في ملفات `assets/data/*.json` / جداول الطلبات الحالية، ونؤجّل ما يحتاج `store_id` وأدواراً (SaaS) إلى مرحلة لاحقة.

## المرحلة 1 — واجهة وإنتاجية (بلا تغيير في الخلفية)
| الأداة | الحالة |
|---|---|
| **بحث شامل Ctrl+K / "/"** (أقسام، منتجات، طلبات، صفحات، إجراءات، مساعدة) — `assets/js/admin-search.js` | أُنجز v1.56.0 |
| صفحة رئيسية للوحة (Dashboard) بالتصميم الزجاجي: مبيعات، طلبات، مخطط، حلقة الحالات، تنبيهات، آخر الطلبات، أفضل المنتجات — `assets/js/admin-home.js` | أُنجز v1.60.0 |
| عروض محفوظة (Saved views) للطلبات + إجراءات جماعية + تصدير CSV — `admin-orders-plus.js` | أُنجز v1.61.0 |
| اختصارات لوحة المفاتيح عامة (g ثم o = الطلبات …) — `admin-keys.js` | أُنجز v1.61.0 |

## المرحلة 2 — أساسيات التاجر
| الأداة | ملاحظات التوافق |
|---|---|
| **المخزون**: كمية لكل منتج/خيار، تنبيه نفاد (≤ حدّ)، خصم تلقائي عند الطلب | يُخزَّن في `data.js` (حقل `stock` موجود)؛ نفس المسار في PHP |
| **المرتجعات والاسترداد (Returns)**: حالة «مرتجع» + سبب + إعادة المخزون | حالة جديدة في الطلبات (Sheets/Supabase/PHP) |
| **الخصومات**: توسيع الكوبونات (نسبة/مبلغ/شحن مجاني/حدّ أدنى/تاريخ/عدد الاستعمال) | الكوبونات قائمة؛ التحقق في الواجهة + الخادم |
| العملاء: شرائح (Segments) وملاحظات ووسوم | جزئي قائم (إعادة الشراء، القائمة السوداء) |

## المرحلة 3 — النمو
- تقارير وتحليلات أعمق (قمع التحويل، مصادر الزيارات، هامش الربح).
- تسويق: حملات واتساب/SMS مجدولة، سلات متروكة.
- الأتمتة (Flow): «إذا طلب جديد ← أرسل واتساب»، قواعد حالات الطلب.
- وكلاء التوصيل: تتبّع وتسعير تلقائي.
- العملاء (شرائح + سجلّ + وسوم) وتعديل المنتجات الجماعي مع CSV — `admin-customers.js`/`admin-bulk-products.js` | أُنجز v1.64.0 (Codex).
- العملاء (شرائح + سجلّ + وسوم) وتعديل المنتجات الجماعي مع CSV — `admin-customers.js`/`admin-bulk-products.js` | أُنجز v1.64.0 (Codex).
- السوشيال والإعلانات: جدولة منشورات فيسبوك/إنستغرام بعدد يومي + مولّد مسودات + إدارة حملات وقياس ROAS بنسبة الطلبات — `admin-social.js` + `scripts/social-publish.js` | أُنجز v1.63.0 (لاحقاً: إنشاء إعلانات عبر Marketing API، ردود التعليقات).

## المرحلة 4 — المنصة (SaaS)
`store_id` متعدد المتاجر، صلاحيات وأدوار (Staff)، Extensions عبر `PB.WIDGETS`، Webhooks وAPI أولاً، نظام تصميم خاص (راجع `docs/shopify-architecture-report.md`).

## ثوابت التنفيذ
- أي سطح عائم (نافذة/قائمة) بخلفية معتمة صريحة في CSS؛ الأزرار زجاجية شفافة بنص أبيض؛ بلا إيموجي في الواجهة الجديدة.
- كل أداة تُسجَّل في `assets/data/admin-help.json` (اسألني) وفي CLAUDE.md، وتُرفع `VERSION` ثم `scripts/build-admin-pb.py`.
