**ماذا لا تغطي:** جودة التصميم (راجعها بصرياً في الدفعات)، التثبيت الفعلي على الرئيسية/صفحات المنتجات (يُنشر)، متجر بمنتجات حقيقية، الأجهزة والمتصفحات الأخرى، البريد والرابط الحقيقيين لنماذج الاتصال، شركات التوصيل.
