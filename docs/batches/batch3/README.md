# الدفعة 3 — أربعة متاجر عامة: s-aurora · s-gold · s-fresh · s-pop

الفرع `feature/alyssum-theme-studio` (لا دمج في `main`؛ لا `s-alyssum`؛ لا قوالب خارج الدفعة). لا إعادة تدوير لتخطيطات الدفعتين: كل قالب هوية وهيرو وعرض منتجات وسرد مستقلة (جدول التمييز أدناه).
المولّد: `scripts/gen-templates-batch3.py` (مولّد معرّفات معزول لكل قالب؛ يستعير ثيم كل قالب — الألوان والخط والترويسة والتذييل والعدّادات والآراء — من تعريفه الأصلي في `gen-templates-store.py` فتبقى هويته اللونية). الصور: كل صور الأصل ومراجعها محفوظة ولا صور مضافة (`IMAGE-AUDIT.md`).

## ما يميّز كل قالب (هيرو · عرض منتجات · سرد)

| القالب | الهوية | الهيرو | عرض المنتجات | السرد |
|---|---|---|---|---|
| **s-aurora** مدار | داكن بنفسجي/سماوي/وردي، أورورا متحركة | **صورة بيضاوية** بنسبة 4:5 داخل **مدارين دوّارين** (متقطع ونقطي) مع **ثلاث شرائح زجاج عائمة** (توصيل/أصلية/هدية) — عناصر حرة مستقلة | **رفّ نيون أفقي** (تمرير بالسحب والتثبيت) ببطاقات زجاجية يضيء حدّها عند المرور | **لوح بنتو**: خلية كبرى (عنوان + نقاط) وأربع خلايا مزايا ملوّنة، فئات كبوّابات طويلة بحدّ نيون |
| **s-gold** دار الذهب | أسود وذهب، El Messiri | **بطاقة دعوة** بإطار ذهبي مزدوج وزخرفة معيّن فوق صورة المجوهرات الأصلية (`jewel_dark` خلفية ثابتة) مع **أشعة آرت ديكو** وكلمتين عموديتين | **فتارين مرقّمة** `N° 01…` بإطار داخلي مزدوج وزرّ مفرَّغ يمتلئ بالمرور | لوحات فئات بإطار داخلي، قصة الدار بفاصل ذهبي رفيع وجدول مقارنة، **مزايا بلا بطاقات** بخطوط فاصلة رفيعة |
| **s-fresh** نقاء | أخضر منعش وباستيل، Almarai | **كتلة عضوية متحوّلة** (تتغيّر حوافها ببطء) تحمل صورة المنتج مع بطاقتي ميزة بيضاوين عائمتين وحافة متموّجة أسفل القسم | **رفّ باستيل**: بطاقات بألوان فاتحة متدرّجة، **صور دائرية** بإطار أبيض، سعر كحبّة خضراء وزرّ كبسولة يقفز بالمرور | فئات **حبّات بيضاوية**، «الوصفة في ثلاث خطوات» بحبّات مرقّمة، مزايا ببطاقات ناعمة |
| **s-pop** بوب ماركت | أصفر منقّط وحدود سوداء وظلال صلبة، Changa | **عنوان ضخم بحدّ صلب** + حذاء داخل **انفجار نجمي دوّار** + **تذكرة** (مخزون وعدّاد أصليان) + **شريط تحذير مائل** | **صفوف ملوّنة** (صورة + اسم + سعر بحبّة سوداء + زر) مرقّمة `#01…`، تتحول عمودية على التابلت والجوال | بلاطات فئات **مائلة متوازية الأضلاع**، «لماذا نحن؟» مع **شرائط خطوات** متراصّة مائلة بأرقام مفرَّغة |

التمييز مقابل ما سبق (هيرو · منتجات · سرد): لا تتكرر الثلاثية بين القوالب الستة عشر؛ المدارات الدوّارة والرفّ الأفقي ولوح البنتو، وإطار الدعوة المزدوج وأشعة آرت ديكو والفتارين المرقّمة، والكتلة العضوية والصور الدائرية على بطاقات الباستيل، والانفجار النجمي والصفوف الملوّنة وشرائط الخطوات — كلها غير موجودة في الدفعتين ولا في التجربتين.
