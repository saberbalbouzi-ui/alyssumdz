# مرجع التصميم: لوحة SaaS «زجاج داكن أخضر» (لقطة أرسلها صاحب المتجر)

> محفوظ بطلب صاحب المتجر ليُبنى عليه مخطط العمل. الوصف أدناه مأخوذ من اللقطة (لا أملك ملف الصورة نفسه؛ إن أردت حفظ الصورة في المستودع فضعها في `docs/img/` وأخبرني).
> الاسم في اللقطة: **ALYSSUM — SaaS Platform**، واجهة عربية RTL.

## 1. الهوية البصرية
- **الخلفية:** أسود نقي (#000) بلا تدرجات ثقيلة.
- **الأسطح:** زجاج أخضر مدخَّن شفاف (تدرّج من أخضر مضيء خفيف إلى أسود مخضرّ)، حواف مدوّرة كبيرة (≈20–28px)، حدّ أخضر رفيع مضيء (≈1px) وتوهّج خارجي خفيف؛ الشريط الجانبي إطار واحد مدوّر كبير.
- **اللون الأساسي:** أخضر ليموني فلورسنت (≈#86f06a) للأزرار الأساسية والعنصر النشط والمخططات والشارات الإيجابية.
- **ألوان البطاقات الإحصائية (4 ألوان زجاجية):** أخضر (المبيعات)، سماوي/أزرق (الطلبات)، كهرماني/ذهبي (العملاء)، بنفسجي (المنتجات)؛ كل بطاقة: حدّ ملوّن مضيء + أيقونة داخل مربع زجاجي + رقم كبير + نسبة تغيّر بسهم + مخطط مصغّر (sparkline أو أعمدة) بنفس اللون.
- **النصوص:** أبيض للعناوين والأرقام، رمادي فاتح خافت للتسميات؛ العناوين أكبر وأثقل، والتفاصيل أصغر وأخفّ.

## 2. التخطيط (من اليمين إلى اليسار)
1. **الشريط الجانبي (يمين):** الشعار + اسم المنصة + زر طيّ ‹؛ ثم القائمة: لوحة التحكم (نشط بتدرّج أخضر مضيء)، الطلبات (شارة عدد 12)، المنتجات، العملاء، المتاجر (شارة 3)، المحتوى، التسويق، التحليلات، التطبيقات، فاصل، الإعدادات؛ وفي الأسفل بطاقة «متجر ALYSSUM» (اسم المتجر الحالي + سهم للتبديل).
2. **الشريط العلوي:** بحث عام (pill) بنص «ابحث عن منتج، طلب، عميل…» واختصار `Ctrl + K`؛ أيقونات: إشعارات (شارة 5)، رسائل، تبديل الوضع الليلي؛ قائمة المستخدم (صورة + «أحمد / مدير المتجر» + سهم).
3. **الترحيب:** «مرحباً أحمد» + سطر وصف («هنا نظرة عامة على متجرك ومبيعاتك اليوم») + منتقي فترة («اليوم») + زر أخضر «إضافة منتج جديد +».
4. **صف بطاقات الإحصاء (4):** إجمالي المبيعات `245,780 دج` (+12%)، عدد الطلبات `168` (+8%)، عدد العملاء `1,245` (+18%)، عدد المنتجات `36` (+4%).
5. **صف المخططات:**
   - «مخطط المبيعات» (مساحة/خط أخضر مع نقاط، تلميح عند التمرير بقيمة وتاريخ، محور أيام الأسبوع، منتقي «هذا الأسبوع»).
   - «قنوات المبيعات» (حلقة Donut بإجمالي المبيعات في المنتصف + وسيلة إيضاح: المتجر الإلكتروني 52%، إنستغرام 20%، فيسبوك 15%، أخرى 13%؛ منتقي «حسب القناة»).
6. **صف القوائم:**
   - «آخر الطلبات»: جدول (رقم الطلب، العميل بصورة، المنتجات بصور مصغّرة، المبلغ، الحالة، التاريخ، قائمة ⋯) + «عرض الكل».
     شارات الحالة (زجاج ملوّن): قيد المعالجة (كهرماني)، مدفوعة (أخضر)، تم الشحن (أزرق)، ملغاة (أحمر).
   - «أفضل المنتجات مبيعاً»: ترتيب 1–5 بترقيم ملوّن، صورة المنتج، الاسم، عدد المبيعات، شريط تقدّم ملوّن، السعر، قائمة ⋯ + «عرض الكل».

## 3. ما أُنجز منه وما تبقى
- **منجز (v1.41.0):** مظهر الزجاج الداكن العام (خلفية سوداء، أسطح زجاجية مخضرّة، شريط جانبي مدوّر، أزرار فلورسنت، عناوين مميّزة، جداول وشارات، محرّر الصفحات) مع زر «المظهر» للتبديل؛ الملفان `assets/css/admin-glass.css` و`admin-glass-auto.css` (مولَّد بـ`scripts/gen-glass.py`).
- **تبقى (مقترح مخطط العمل):**
  1. صفحة «لوحة التحكم» الرئيسية الجديدة (الترحيب + 4 بطاقات + مخططان + جدولان) من بيانات الطلبات الحقيقية (الطلبات/الزبائن/المنتجات الموجودة)، مخططات SVG/Canvas بلا مكتبة ثقيلة.
  2. الشريط العلوي: بحث عام `Ctrl+K` (لوحة أوامر تفتح الأقسام والمنتجات والطلبات)، مركز إشعارات، قائمة المستخدم.
  3. شارات أعداد على عناصر القائمة (الطلبات الجديدة…) وطيّ الشريط الجانبي.
  4. توحيد مكوّنات: بطاقة إحصاء، جدول زجاجي، شارة حالة، منتقي فترة، حلقة نسب — كنظام تصميم (على نهج Polaris، انظر `docs/shopify-architecture-report.md`).
  5. مراجعة بقية الشاشات (التحليلات، الإعدادات، النوافذ المنبثقة) وإزالة بقايا الفاتح.
  6. لاحقاً (المنصة): `store_id` متعدد المتاجر، صلاحيات، أحداث/Webhooks.
