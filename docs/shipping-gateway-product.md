# منتج «بوابة الشحن» — خطة البيع

**الفكرة (بقرار صاحب المتجر):** بناء خدمة مثل dzship «بل أفضل» وبيعها داخل منصتنا. الكود: `php-edition/shipping/gateway/` (انظر README هناك). المرحلة 1 مُنجزة (v1.89.139): API كاملة + مفاتيح وخطط وحدود + خزنة + webhooks + sandbox + توثيق + CLI + اختبارات.

## موقعنا مقابل dzship (من توثيقهم العلني)
| | dzship | بوابتنا |
|---|---|---|
| السعر / التسجيل | مجاني بلا تسجيل | خطط مدفوعة (التسعير مفتوح) |
| المفاتيح | تمرّ مع كل طلب ولا تُحفظ | inline **أو** خزنة مشفّرة |
| تحديثات الحالة | استعلام فقط | webhook وارد + تزامن + **webhook صادر موقَّع** |
| تكرار الطرد | غير مذكور | idempotency بالمرجع |
| العنوان | يُرفض إن أخطأت البلدية | تصحيح إملائي + `/v1/validate` |
| الحدود | 200 طلب/ساعة/IP | حسب الخطة لكل مفتاح |
| التغطية | 99 شركة موثّقة | ياليدين + عائلة Ecotrack وغيرها (**تجريبية عدا ياليدين**) — **هذه فجوتنا الأكبر** |
| rates / desks حيّة / إلغاء / بوليصة | نعم (حسب الشركة) | desks من كتالوج ثابت؛ rates والإلغاء والبوليصة غير مكشوفة بعد |

## قرارات تنتظر صاحب المتجر
1. **الاسم والنطاق** (لا يُشترى شيء قبل قرارك؛ انظر `docs/multitenant-plan.md` §11).
2. **التسعير:** اقتراح للبدء — مجانية (حدود صغيرة، sandbox) / احترافية / أعمال بأرقام يحددها الطلب الحقيقي؛ `php admin.php plan:price`. الدفع: RedotPay/PayPal كما في خطة المنصة (غير مبنيّ).
3. **الاستضافة:** PHP + SQLite يكفي للانطلاق؛ للحجم الكبير MySQL/Postgres + Redis للحدود.
4. **المسؤولية القانونية:** مفاتيح العملاء لدينا (في الخزنة) = مسؤولية حفظ. يلزم شروط استعمال وسياسة خصوصية وPDA قبل أول عميل مدفوع (ANPDP).
5. **الموقع:** مستقل (`api.<نطاق>`) لا على `alyssumdz.com`.

## الخارطة
- **ج1 (مُنجز):** النواة والخزنة والـwebhooks والتوثيق.
- **ج2 (الأهم للبيع):** اختبار محوّلات الشركات على حسابات حقيقية وتوثيقها (ZR، Maystro، NOEST، Ecotrack) ← رفع «تجريبية» إلى «موثّقة»؛ `/v1/rates` (رسوم التوصيل والإرجاع)؛ الإلغاء والبوليصة في REST؛ سجلّ أحداث لكل طرد (`events[]`).
- **ج3:** لوحة عميل (مفاتيح، استعمال، سجلّ الطلبات، اختبار مباشر) ولوحة مزوّد داخل `saas/`؛ الفوترة والاشتراكات.
- **ج4:** SDK (PHP/Node) ومكوّن Shopify/WooCommerce/Landing pages؛ ربط متجرنا ولوحتنا كأول عميل.
- **ج5:** MySQL/Postgres، Redis، مراقبة (إنذار حين تتغير واجهة شركة)، حدّ لكل هاتف زبون، IP allowlist لكل مفتاح.

## مخاطر
- شركات التوصيل قد تغيّر واجهاتها دون إعلان (أغلبها غير موثَّق): يلزم اختبار آلي دوري بحسابات تجريبية وإنذار.
- منافسة مجانية (dzship) ← نتميّز بالموثوقية (push، idempotency)، والدعم بالعربية، والخزنة، والتكامل مع متجرنا.
