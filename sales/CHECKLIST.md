# قائمة تسليم زبون (انسخها لكل زبون)

**الزبون:** ______  **التاريخ:** ______

## قبل التسليم
- [ ] النطاق والاستضافة مسجّلان **باسم الزبون** (أو بحسابه).
- [ ] الاستضافة PHP 8.1+ مع `pdo_sqlite` و`fileinfo` و`mbstring` (hPanel ← Configuration PHP ← Extensions).
- [ ] حزمة الزبون مولّدة: `./scripts/new-client.sh <id> "اسم المتجر" 2135XXXXXXXX` ورمز التثبيت مدوّن.

## التثبيت (مع الزبون)
- [ ] رفع الـzip إلى `public_html` واستخراجه.
- [ ] `install.php`: اسم المتجر، واتساب، النطاق، **كلمة مرور يختارها الزبون** (10 أحرف+).
- [ ] تأكد أن `install.php` حُذف (فتحه يعطي 404).
- [ ] تأكد أن `…/api/_data/store.db` و`…/api/config.php` لا يُحمَّلان (403/404).
- [ ] تفعيل HTTPS (شهادة SSL) على النطاق.

## التجربة
- [ ] طلب تجريبي من صفحة المنتج → يظهر في اللوحة، وتغيير حالته يعمل.
- [ ] إضافة منتج جديد من اللوحة → تُنشأ صفحته ويفتح رابطها.
- [ ] رفع صورة رأي زبون من الجهاز في وضع تعديل الصفحة.
- [ ] تعديل رسوم توصيل ولاية والتأكد من ظهورها في الطلب.
- [ ] حذف المنتج التجريبي `demo`.
