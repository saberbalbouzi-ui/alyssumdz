# ALYSSUM 2030 — مركز القيادة المكاني (معاينة تجريبية معزولة)

تصميم بصري بديل كلياً للوحة (اتجاه مختلف عن `admin-preview/holographic/`). لا يلمس اللوحة الأصلية ولا أي API ولا قاعدة بيانات؛ كل الأرقام **بيانات تجريبية** معلَن عنها في الشريط العلوي والتذييل.

## التشغيل
```bash
python3 -m http.server 8765
# http://localhost:8765/admin-preview/spatial/
```
ملفات ثابتة بلا مكتبات ولا بناء.

## البنية التقنية (لا مكتبة 3D)
- `core.js` — نواة ALYSSUM: مجسّمان متداخلان (عشروني وجوه + ثماني وجوه) بإسقاط منظوري على Canvas 2D، حلقات مدارية، حلقة قطاعات لحالات الطلبات بعقد مضيئة تتفاعل مع المؤشر (تحويم/نقر/سحب للتدوير)، وجسيمات تتدفق نحو القلب مع دمج إضافي (bloom).
- `terrain.js` — سطح طاقة سلكي بعمق ومنظور: صفّه الأمامي هو البيانات (عقد قابلة للتحويم) وخلفه امتداد ناعم، مع تدفّق طاقة يمرّ على السطح.
- `spatial.css` — بيئة (أشعة، ضباب، أرضية بمنظور)، أسطح عائمة بحواف مشطوفة وCSS 3D (لوحة مائلة، أعمدة إيراد مجسّمة حقيقية)، بارالاكس بعمق لكل طبقة.
- `app.js` — بيانات وهمية حتمية، ربط المكوّنات، سكّة جانبية بقوائم عائمة وبحث (مفتاح `/`)، فترات `1/2/3`، خطوط طاقة متحرّكة تربط النواة بالأسطح.

## الأداء وإمكانية الوصول
حدّ إطارات لكل canvas، تتوقف الحركة عند إخفاء التبويب، ولا `backdrop-filter`. يحترم `prefers-reduced-motion` (إطار ثابت بلا حركة). على الهاتف تتبسّط الطبقات إلى عمود واحد وتصير السكّة شريطاً سفلياً.

## الحذف
احذف `admin-preview/spatial/` كاملاً؛ لا شيء يعتمد عليه.
