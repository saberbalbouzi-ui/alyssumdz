# voice-eval — حزمة التقييم الصوتي (المرحلة 12 / WS2)

| ملف | الغرض |
|---|---|
| `sentences.json` | 66 جملة تقييم (دارجة وسط/شرق/غرب، فصحى، فرنسية، إنجليزية، مخلوط، أرقام/معرّفات، منتجات، مفردات تاجر، قصيرة/طويلة، متابعات، جمل أمان) مع الأداة المقصودة والخطورة |
| `score.js` / `selftest.js` | WER/CER، دقة المعرّف، اللغة، الأداة (المحلّل الحقيقي) — مع اختبار ذاتي بنصوص اصطناعية (14/14) |
| `eval.js` | `--oracle` (نص ← محلّل، بلا صوت) · `--audio` (تسجيلات خارجية) · `--tts-sheet` |
| `PROTOCOL.md` | بروتوكول تسجيل الصوت وقائمة المالك وحدود القبول |
| `oracle-result.json` | نتيجة الوضع المرجعي (ليست تحققاً صوتياً) |
| `audio-result.json` | حالة وضع الصوت (BLOCKED حتى توفّر تسجيلات + مفتاح) |

لا تسجيلات في هذا المجلد ولا في المستودع (`.gitignore`).
