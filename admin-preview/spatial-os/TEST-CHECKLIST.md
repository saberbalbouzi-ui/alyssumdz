# قائمة اختبار التفاعلات — Spatial OS (معاينة معزولة)

**آلي:** `python3 -m http.server 8765` من جذر المشروع ثم
`NODE_PATH=/opt/node-tools/node_modules node admin-preview/spatial-os/test/run.js [desktop|mobile]`
(79 فحصاً؛ آخر تشغيل: كلها نجحت، مرتين متتاليتين). الوسم بين [ ] هو **طريقة** الاختبار: `mouse`/`keyboard` فأرة ولوحة مفاتيح حقيقيتان، `cdp-touch` لمس حقيقي عبر بروتوكول المتصفح، `synthetic` أحداث Pointer مُنشأة برمجياً (لا تثبت سلوك إصبع حقيقي)، `api` قراءة حالة التطبيق.
**تسجيل:** `node admin-preview/spatial-os/test/record.js <مجلد>` ← `desktop.webm` و`mobile.webm` بعنوان لكل تفاعل.

## قيود البيئة عند الاختبار
- الاختبارات تعمل بمتصفح بلا GPU (تصيير برمجي): الإطارات بطيئة، لذا بُنيت معادلات الحركة على **الزمن الحقيقي** لا على عدد الإطارات، وأُجريت الإيماءات السريعة بأحداث مصطنعة حيث لزم وأُعلن ذلك.
- لم يُختبر: Safari/iOS، أجهزة ضعيفة (الأداء)، قارئ شاشة، `prefers-reduced-motion` (منفَّذ دون اختبار)، أكثر من 6 ألواح.
