# ALYSSUM Spatial OS — اسطوانة سحابية وألواح عائمة (معاينة تفاعلية معزولة)

لا تلمس اللوحة الأصلية ولا API ولا قاعدة بيانات؛ كل البيانات تجريبية. مكتبات: لا شيء (CSS 3D + Pointer/Touch Events + Canvas 2D).

```bash
python3 -m http.server 8765
# http://localhost:8765/admin-preview/spatial-os/
```

## البنية
- `spatial.js`: المشهد (اسطوانة 24 وجهاً + اسطوانة داخلية معاكسة + حلقات + 11 عقدة مدارية) ومدير الألواح (فتح/تركيز/سحب/تدوير/تحجيم/رمي/تصغير/استعادة/تخطيط تلقائي).
- `panels.js`: محتوى 11 قسماً + مساعد ALYSSUM. `AI.ask` هو نقطة التوصيل المستقبلية (`AI.endpoint`).
- `fx.js`: جسيمات الخلفية ودفقات الظهور والتلاشي.

## الإيماءات والتفاعلات
الجدول المفصَّل بطريقة الاختبار لكل إيماءة (حقيقي/مصطنع) وما لم يُجرَّب في **TEST-CHECKLIST.md**. التشغيل الآلي: `test/run.js` (68 فحصاً)، والتسجيل: `test/record.js`.

أهم ما أُضيف في مرحلة الهندسة التفاعلية:
- **تحديد القسم**: تظليل العقدة + تدوير سلس نحو المستخدم + أسهم لوحة المفاتيح وEnter وTab وEsc.
- **المدار**: الألواح تدور حول الاسطوانة (الخلفية منها خلفها)، والمؤشر فوق لوح يوقف دورانه، وسحبه بعيداً يحرّره، والإفلات قربه أو زر ◎ يعيده (snap-to-orbit)، ومفتاح «المدار» يعيد التخطيط الثابت.
- **حفظ الحالة**: التصغير يُبقي اللوح بمحتواه وتمريره؛ الإغلاق/الرمي يحفظ حالة المحتوى (فلتر الطلبات، محادثة المساعد) وحجمه لإعادة الفتح.
- **إصلاح خلل المخزون الموسَّع**: (1) المحتوى كان سليماً لكنه ثلاثة صفوف تتمدّد في لوح 920×660 بلا تخطيط موسَّع، فصار لكل لوح تخطيط موسَّع غني (جدول حركة المخزون والأصناف، جدول الطلبات الكامل، قمع التحويل…)؛ (2) اللوح الموسَّع كان يحتفظ بشفافية المدار (0.84) وقد يبقى في الطبقة الخلفية فيبدو باهتاً؛ صار معتماً وفي الطبقة الأمامية.
- **أخطاء إيماءات وُجدت بالاختبار وأُصلحت**: إعادة إلحاق عنصر اللوح بالـDOM عند أول سحب كانت تُسقط التقاط المؤشر فيفشل الرمي أحياناً؛ القصور الذاتي والتسهيل صارا مبنيين على الزمن الحقيقي؛ زر ◎ كان يبتلعه التقاط الترويسة؛ أزرار الـHUD كانت تغطّي ترويسة اللوح الموسَّع على الهاتف.

## الحدود المعلنة
- **المكوّنات الحقيقية**: محتوى الألواح هنا بيانات تجريبية بنفس شكل سجلات المتجر (id/الزبون/الهاتف/الولاية/المنتج/المبلغ/الحالة)، **وليس** مكوّنات لوحة التحكم الحقيقية؛ تلك مرتبطة بكائن `Admin` وبمعرّفات DOM وبواجهة الخلفية ولا يمكن تضمينها دون تشغيل اللوحة كاملة، وهذا يخالف العزل. الخيار المقترح للمرحلة التالية (بموافقتك): تضمين اللوحة الحقيقية في إطار iframe عبر نسخة اختبار محلية بقاعدة بيانات تجريبية.
