## 6) التحقق من المزوّد الحقيقي (WS1) — **BLOCKED**
- **مطابقة الصيغة بالتوثيق الرسمي الحالي (قراءة):** `POST /v1beta/models/{model}:generateContent`، ترويسة `x-goog-api-key`، `systemInstruction.parts`، `contents[].role ∈ {user,model}`، `tools[].functionDeclarations`، `toolConfig.functionCallingConfig.mode`، `functionCall`/`functionResponse` — يطابق `server/llm.php`. - **مخاطرة موثّقة:** التوثيق الحالي يضع Interactions API مساراً أولياً؛ `generateContent` ما زال موثَّقاً لكنه قد يُهجَر لاحقاً. معرّف النموذج الافتراضي `gemini-2.5-flash` **لم يُتحقق من توفّره حياً**.
- **النتيجة:** فحص مباشر للمفتاح ⇒ `HTTP 401 UNAUTHENTICATED / API_KEY_SERVICE_BLOCKED` (قيد على مفتاح المشروع: واجهة Generative Language غير مفعّلة له). **لا طلبات ناجحة، لا زمن، لا نسبة نجاح، لا p50/p95: NOT TESTED.**
- **ما جاهز:** `test/real-provider.js` — السلسلة الكاملة (متصفح ← وسيط PHP موثَّق ← مزوّد ← أداة ← نواة ← أداة قراءة)؛ 34 طلباً عبر: قراءة (18)، أدوات متعددة (3)، توضيح (3)، كتابة→بطاقة فقط (3)، حقن (3)، معرّفات مختلقة (2)، دردشة (2)؛ فحص عدم الكتابة المباشرة وتسرّب المفتاح؛ إخراج `real-provider-result.json`. **الاختبار الذاتي** (`SELFTEST_STUB=1`، على المحاكي) يتحقق من سلامة الأداة فقط ويُوسَم صراحةً «ليس تحققاً».

## 13) قيود معروفة
