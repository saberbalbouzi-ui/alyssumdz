# ALYSSUM Intelligence Engine — بحث وتطوير تجريبي (المرحلة 11A)

> معاينة معزولة على الفرع التجريبي. لا دمج في `main`، لا نشر، لا مفاتيح، لا بيانات زبائن حقيقية، ولا تغيير للمنصة أو قواعد البيانات. كل شيء داخل `admin-preview/spatial-os/`.

الهدف: محرّك ذكاء خاص بأليسوم **منخفض الكلفة المتكررة** يفهم الدارجة الجزائرية والفصحى والفرنسية ويصدر **خطط أدوات مُنمَّطة** متوافقة مع سجل الأدوات القائم، مع توجيه هجيني (حتمي ← محلي ← خارجي اختياري) دون أن يتجاوز أي نموذج نواة الوكيل (سجل الأدوات، مدير الصلاحيات، مدير الموافقة، المحقِّق).

| المجلد | المحتوى |
|---|---|
| `dataset/` | مولّد المجموعة (`gen_dataset.py`)، المجموعة الذهبية اليدوية (`hand_gold.py`)، `registry.json` (مصدّر من `agent/tools.js`)، `alyssum-intel-v0.1/{train,val,test}.jsonl` + `manifest.json` (أعداد، SHA-256، فحوص التسرّب) |
| `bench/` | المسجّل (`score.py`)، خط أساس NLU (`nlu_baseline.js`)، مشغّل النماذج (`run_model.py`)، `run_all.sh` |
| `train/` | ضبط LoRA (`lora_sft.py`) |
| `serve/` | خادم الاستدلال المحلي (`local_server.py`) |
| `cost/` | نموذج الكلفة (`cost_model.py`) والنتائج |
| `results/` | تنبؤات وقياسات كل نموذج (`*.jsonl`, `*.meta.json`) |
| `adapters/` | محوّل LoRA المدرَّب (أوزان صغيرة؛ ليست أوزان أعمال) |

التقرير الكامل: `../PHASE11A-REPORT.md`.
