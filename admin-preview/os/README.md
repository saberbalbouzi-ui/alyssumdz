# ALYSSUM OS — نظام تشغيل التجارة (معاينة تجريبية معزولة)

نموذج تفاعلي كامل للشاشة الرئيسية. **لا يلمس** اللوحة الأصلية ولا أي API أو قاعدة بيانات؛ كل الأرقام بيانات تجريبية حتمية معلَن عنها في شريط النظام. الإجراءات (تأكيد الطلبات، إعادة طلب المخزون…) تغيّر حالة الواجهة فقط وتُحدّث كل اللوحات.

## التشغيل
```bash
python3 -m http.server 8765
# http://localhost:8765/admin-preview/os/
```
ملفات ثابتة بلا مكتبات ولا بناء. `os.v1.css` نسخة الإصدار البصري الأول للمقارنة.

## البنية
- شريط نظام: الهوية، صحة النظام، حالة المتجر (مبدّل حقيقي)، إشعارات، مساعد، حساب.
- سكّة ملاحة يمنى بـ10 أقسام وقوائم فرعية وإجراءات سريعة، وبحث سريع (`/`).
- يسار: أربعة مؤشرات (إيراد، تحويل، متوسط الطلب، اتجاه) تفتح مساحة التحليلات.
- مركز: منحنى مبيعات حجمي مع خط زمني تفاعلي، حلقة مجسّمة لحالات الطلبات (تصفية بالنقر)، قمع تحويل حجمي، ووحدة **ALYSSUM Intelligence** (مجسّم 20 وجهاً + حلقة نشاط + مدارات + دفقات عند كل حدث) باقتراحات سياقية قابلة للتنفيذ.
- أسفل: آخر الطلبات (إجراءات حسب الحالة)، التنبيهات والنشاط، حالة المخزون.
- طبقات: مساحات عمل موسّعة (الطلبات، التحليلات، المخزون) ومساعد ALYSSUM يجيب من بيانات المعاينة وينفّذ بموافقتك.

## التقنية
CSS 3D (ألواح مائلة بسُمك، حلقة مجسّمة، أعمدة قمع بإسقاط مائل، أعمدة إيراد)، Canvas (منحنى المبيعات، وحدة الذكاء)، SVG. بارالاكس بعمق لكل طبقة وإضاءة حافّة متحرّكة. يحترم `prefers-reduced-motion`، ويتبسّط على الهاتف.

## الحذف
احذف `admin-preview/os/` كاملاً؛ لا شيء آخر يعتمد عليه.
