# ALYSSUM — لوحة هولوغرافية (نموذج تجريبي معزول)

معاينة تفاعلية مستقلة تماماً عن لوحة التحكم الحقيقية. **لا تلمس** `admin.html` ولا أي ملف من المنصة، ولا تتصل بشبكة أو API أو قاعدة بيانات؛ كل الأرقام وهمية (حتمية بحسب الفترة).

## التشغيل محلياً
```bash
python3 -m http.server 8765
# ثم افتح: http://localhost:8765/admin-preview/holographic/
```
ملفات ثابتة فقط (HTML + CSS + JS بلا مكتبات ولا بناء). يستعمل خط Cairo المحلي من `assets/fonts/`.

## الملفات
- `index.html` — البنية (RTL) · `holo.css` — النظام البصري · `holo.js` — البيانات الوهمية والتفاعل.

## ما فيه
- شريط علوي (مظهر داكن/فاتح يعمل)، شريط جانبي بقائمة منسدلة وبحث فوري (مفتاح `/`).
- بطل بصري: مرطبان بمنصة وحلقات ولوحات مدارية، كرة أرضية، خريطة الجزائر ونقطة نابضة.
- أربعة مؤشرات بعدّاد متحرك، حلقة حالات الطلبات (تمرير فوقها يميّز الشريحة)، مخطط مبيعات/طلبات بتلميح فوري وعرض جدول.
- مفاتيح الفترة: `1` اليوم · `2` 7 أيام · `3` 30 يوماً.

## الفنّ المرجعي
مجلد `img/` فيه قصاصات شفافة (جرّة المنتج، الكرة، خريطة الجزائر، أيقونات المؤشرات، منصات الإضاءة، اليد) مقتطعة من التصميم المرجعي وقد حُوِّل سوادها إلى شفافية؛ أما النصوص والأرقام والمخططات والحلقة والقوائم فعناصر ويب حيّة. لا تُستعمل هذه الصور خارج هذه المعاينة.

## الأداء وإمكانية الوصول
- جسيمات الخلفية على canvas واحد بحدّ 30 إطاراً/ثانية وتتوقف عند إخفاء التبويب؛ باقي الحركة CSS فقط.
- يحترم `prefers-reduced-motion`؛ أزرار حقيقية مع `aria` وتركيز مرئي؛ متجاوب (هاتف/تابلت/مكتب).

## الحذف
احذف المجلد `admin-preview/holographic/` كاملاً؛ لا شيء آخر يعتمد عليه.
