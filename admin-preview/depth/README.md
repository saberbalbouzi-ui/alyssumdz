# ALYSSUM — شاشات هولوغرافية ثلاثية الأبعاد (معاينة مظهر فقط)

معزولة تماماً: لا تلمس اللوحة الأصلية ولا API ولا قاعدة بيانات؛ الأرقام تجريبية.

```bash
python3 -m http.server 8765
# http://localhost:8765/admin-preview/depth/
```

- منظور حقيقي (`perspective` + `preserve-3d`): كل لوح له إزاحة Z حقيقية (صفحة شفافة ضخمة في الخلف -560، جانبيتان مائلتان نحو المركز، شاشة المبيعات المضيئة، أرضية مائلة أمامية)، وسُمك زجاج من 4 طبقات خلفية.
- بطاقات تخرج من الشاشات (طلب جديد، منتج، CTR، AOV، تنبيه مخزون) بارتفاع Z أمام السطح وساق ضوئية ثلاثية الأبعاد تمتد إلى سطح الشاشة المصدر.
- بارالاكس بالمؤشر (وانجراف هادئ عند الخمول)، وشبكة عُقد خلف الزجاج على صورة بيئة مموّهة.
- الهاتف (≤820px): لوحات متدفقة عمودياً بميلان منظوري خفيف.
- الحذف: احذف `admin-preview/depth/` فقط.
