# Ecommerce SaaS — SVG Image Editor Icons

مجموعة أيقونات SVG مستقلة لمحرر الصور في منصة تجارة إلكترونية SaaS عامة، وليست مخصصة للعسل أو لأي قطاع واحد.

## المحتويات
- 15 ملف SVG مستقل، قابلة للتكبير دون فقدان الجودة.
- واجهة داكنة مع ألوان تقنية متعددة ولمسات أخضر ليموني.
- أيقونة الماسك تتضمن رسماً لرجل بدلاً من امرأة.
- أسماء الأدوات بالعربية ضمن ملف الفهرس، لتبقى الأيقونات نفسها قابلة لإعادة الاستخدام.

## الملفات
mask.svg — ماسك  
puzzle.svg — بازل  
select-elements.svg — التقاط العناصر  
remove-background.svg — نزع الخلفية  
retouch.svg — لمسات وتصحيح  
product-studio.svg — استوديو المنتج  
frame-photo.svg — إطار وصورة  
soft-edges.svg — حواف ناعمة  
merge-images.svg — دمج صور  
collage.svg — كولاج  
image-to-video.svg — فيديو من الصورة  
expand-background.svg — توسيع الخلفية بالذكاء  
smart-scene.svg — مشهد ذكي للمنتج  
smart-photo-styles.svg — أساليب تصوير ذكية  
edit-by-prompt.svg — تعديل بالوصف  
smart-brush-eraser.svg — ممحاة ذكية بالفرشاة  

## الاستخدام
يمكن تضمين الملفات مباشرة:
`<img src="/icons/mask.svg" alt="ماسك">`

أو عرض SVG inline داخل التطبيق لتخصيص الألوان عبر CSS. الأيقونات مستقلة ومبنية من عناصر SVG vectorية وليست صور PNG مضمّنة.

ملاحظة: الرسوم المصغرة هي تصورات رمزية للوظائف وليست صور منتجات واقعية.
