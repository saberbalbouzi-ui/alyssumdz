# beta-content — محتوى متاجر Beta فقط (بيانات)

هذا المجلد (أو فرع `beta-content` المعزول بالمحتوى نفسه) يحمل **محتوى متاجر Beta** وحده: بيانات متاجر تجريبية وصفحات JSON وصور. **ليس مصدراً لشيفرة المنصة** ولا يدخل بناءها.

القواعد (تُفحص آلياً في `beta-release.mjs verify` وفي CI، وتُرفض المخالفة قبل أي نشر):
- امتدادات مسموحة: `json md txt png jpg jpeg webp gif avif` فقط. لا `.js/.html/.svg` ولا أي تنفيذي.
- لا شيفرة داخل ملفات المحتوى (وسوم السكربت وروابط جافاسكربت ودوال التقييم وما شابهها): يفحصها `validateBetaContent` نصياً ويرفض الملف.
- `manifest.json` إلزامي: `{ "schema": 1, "kind": "beta-content", "stores": [...] }`.
- لا ملف شيفرة في المنصة (`platform/` و`scripts/` و`assets/js/` وworkflows) يقرأ من هذا المجلد أو يستورده؛ المسموح: أدوات `platform/release/` والتوثيق والاختبارات.
- لا بيانات من Production هنا (لا متاجر ولا طلبات ولا عملاء حقيقيون): محتوى اصطناعي أو عام فقط.
- تحديث الشيفرة (نشر Beta) **لا يمسح** بيانات Beta ولا يستبدل محتوى المتاجر المعدَّل؛ هذا المحتوى لا يُطبَّق على الإنتاج أبداً.

> الحالة: المجلد جاهز للاستعمال والفحص. **تطبيق المحتوى على متاجر Beta عبر API (إنشاء متاجر/صفحات إن غابت دون استبدال الموجود) غير منفَّذ بعد** — يحتاج عقد API لإنشاء المتاجر؛ انظر docs/BETA-SYNC.md.
