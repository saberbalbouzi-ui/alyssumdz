## البنية
- `content/{en,fr,ar}.json` — كل النصوص (البنية متطابقة تماماً ويفحصها `test.js` كاختبار «parity»؛ `*كلمة*` في العناوين = إبراز بلون الحملة). أقسام الصفحة: هيرو (رحلة الزائر + عيّنة اللغات الثلاث + «ما يمكنك فحصه»)، التموضع، الخدمات (٩ في ٣ مجموعات، ٤ أولوية، لكل خدمة: المشكلة/المخرجات/الأنسب/ما تقدّمه/زر يختارها في النموذج)، المخرجات (ما تتسلّمه + ٦ أمثلة مخرجات موسومة «مثال توضيحي» + البحث والتحقق والاعتماد)، النماذج (٣ نماذج موسومة «نموذج توضيحي — وليس عملاً لعميل»)، المنهج (٤ مراحل بمخرجات ونقطة اعتماد)، القطاعات، الأسئلة، التواصل.
- `css/site.css` — نظام التصميم (خصائص منطقية فقط: يعمل LTR وRTL من ملف واحد).
- `js/site.js` — تفاعلات بلا مكتبات (قائمة الجوال، كشف عند التمرير، مبدّل اللغة الذي يحفظ القسم، التحقق من النموذج).
- `build.py` — يولّد الصفحات الثلاث (+ `seo-urls.txt` لخريطة الموقع، يلتقطه `scripts/seo.py`).
- `og.js` — صور المشاركة 1200×630 بنفس الخطوط (تُضمَّن كـ data: URL لأن `setContent` لا يقرأ file://). `test.js` — اختبارات القبول (Playwright + axe).
- `social.json` — روابط التواصل الاجتماعي للتذييل `{"LinkedIn": "https://…"}`؛ فارغ الآن فلا يظهر شيء (لا روابط وهمية).

## التعديل
```
# عدّل content/*.json أو css/site.css أو js/site.js ثم:
python3 scripts/saber-digital-pro/build.py
NODE_PATH=/opt/node-tools/node_modules node scripts/saber-digital-pro/og.js     # إن تغيّر العنوان/الوسوم
```
تغيير النطاق (canonical/hreflang/OG/JSON-LD): `SDP_BASE=https://نطاقك/مسار python3 scripts/saber-digital-pro/build.py`.

## الاختبار
```
python3 -m http.server 8765        # من جذر المستودع
NODE_PATH=/opt/node-tools/node_modules SDP_AXE=/path/to/axe.min.js node scripts/saber-digital-pro/test.js
```
يغطي: تطابق مخطط ملفات المحتوى الثلاثة، SEO وhreflang وJSON-LD، «لا إثباتات مختلقة» (أعداد/تقييمات/جوائز/شهادات) وإفصاح العيّنات، بنية الأقسام وعدّ العناصر، الروابط والمراسي، عدم وجود تمرير أفقي من 320 إلى 1920، RTL، لوحة المفاتيح، مبدّل اللغة، النموذج بحالاته (٤ حقول مطلوبة وحقلان اختياريان، حالة «جاهز — لم يُرسَل بعد»، لا إرسال تلقائي، ٩ أزرار خدمة تختار خدمتها)، عرض الجوال (هيرو داخل أول شاشة، بلا تجاوز عند 390 و320، أهداف لمس ≥ 36px)، قائمة الجوال، تقليل الحركة، بلا JavaScript، وaxe (WCAG 2.2 AA).

## النموذج
نموذج من مرحلتين بلا خادم: (١) الحقول المطلوبة أربعة فقط — الاسم والبريد والخدمة وملخّص المشروع — أما الشركة والموقع فاختياريان داخل «أضف…»؛ (٢) بعد التحقق تُعرَض رسالة جاهزة بلغة الصفحة بعنوان «طلبك جاهز — لم يُرسَل بعد» ويختار الزائر بنفسه واتساب (`wa.me/213697236128`) أو البريد (`mailto:saberdigitpro@gmail.com`) أو النسخ؛ لا يُفتح شيء تلقائياً ولا تظهر علامة نجاح توحي بالاستلام. نص مساعد تحت الزر وقائمة «ماذا يحدث بعد ذلك» يشرحان ذلك. بلا JavaScript يعمل `action="mailto:…"` احتياطاً. لإرسال مباشر من الصفحة يلزم نقطة نهاية خادم (لم تُحدَّد).
