# الصوت والمساعد

- **المحرّك نقي:** `AdminVoice.parse(text,data)` ← `{kind,say,act}` ثم `exec(act)`؛ تطبيع ← `understand` (نية/منتج/كمية/مرجع «هذا»/نفي) ← قواعد ← فهرس كلمات. **أضف صيغاً في `assets/data/voice-lexicon.json` لا في الشيفرة**، ثم مثالاً في `examples`.
- **أوامر تغيّر بيانات تطلب تأكيداً؛ الحذف لا يُنفَّذ بالصوت (يفتح فقط)؛ كمية غامضة تُسأل.**
- **مسار حواري جديد:** تعريف في `FL` (order/match/parse/ask/done) + حالة في `flowDo` + حالات `FT` في test-voice.js + فحص في test-hand.js.
- **ذاكرة المحادثة:** `MEM`، وضمائر غائبة `PRON_BASES`، ومتابعات `followUp`؛ كلمة جديدة لخاصية A_* أو ضمير تُضاف مع مثال.
- **اليد:** `execVia` تنقر/تكتب بعناصر اللوحة الحقيقية (لا منطق موازٍ)؛ غياب العنصر ← تنفيذ مباشر. الفهرس الحي `uiBuild/findUI` يلتقط الأزرار الجديدة تلقائياً؛ `HAND_CHECKS` فحص ذاتي لما تعتمد عليه اليد.
- **«اسألني»:** كل أداة/إعداد جديد يحتاج مقالاً في `assets/data/admin-help.json` (`id,t,k,a,go`) — بصياغة للعميل بلا مصطلحات تقنية. شروح الإعدادات في `ctl-help.json`.
- **النطق:** `prepSpeech/chunkSpeech/rankVoices`؛ الصوت الاحترافي بمفتاح المستخدم فقط؛ لا نموذج للدارجة الجزائرية.
- **حدود صريحة:** Web Speech نص لا بصمة صوتية؛ لم يُجرَّب بميكروفون حقيقي.
- **الوكيل الذكي للزائر:** `agent.js` (واجهة وردود) + `agent-brain.js` + `assets/data/agent-training.json`؛ يقرأ `window.STORE` (حسابات التواصل) ولا يذكر إلا أسعار المناطق.
