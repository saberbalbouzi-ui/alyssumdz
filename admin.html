ربط شركات التوصيل الجزائرية
أسعار التوصيل نفسها مفصولة تماماً عن المنتجات وتُدار من تبويب «🚚 رسوم التوصيل» أعلاه (تعديل يدوي لكل ولاية). هذا التبويب خاص فقط بربط حساب/مفاتيح API لكل شركة توصيل لإرسال الطلبات المؤكدة إليها مباشرة من لوحة التحكم. المفاتيح تُخزَّن فقط داخل متصفحك (localStorage) ولا تُنشر أبداً على GitHub لأن الموقع عام بدون تسجيل دخول.
أكواد الخصم (Coupons)
يظهر حقل إدخال الكود تلقائياً في صفحة كل منتج ودرج السلة — لا حاجة لتعديل كل صفحة يدوياً. ملاحظة: الأكواد تُنشر كملف عام على GitHub (assets/data/coupons.json) مثل بقية إعدادات الموقع، فهي ليست سرّية بالمعنى الأمني — مناسبة لأكواد ترويجية عادية وليست لصلاحيات حساسة.
القائمة السوداء لأرقام الهواتف
لحماية متجرك من الطلبات الوهمية أو المتكررة في الإلغاء — محفوظة فقط داخل هذا المتصفح (localStorage) مثل مفاتيح شركات التوصيل، لأنها بيانات تشغيلية خاصة بمتجرك ولا تُنشر أبداً على GitHub. رقم محظور يظهر بجانبه تنبيه 🚫 في تبويب الطلبات، لكن لا يمنع تلقائياً إرسال طلبات جديدة (الموقع عام بلا خادم) — الفائدة هنا تنبيهية عند المعالجة اليدوية.

🧾 نموذج الطلب
تحكم كامل في نموذج طلب المنتج: الألوان، الحقول، الأزرار، العروض، ورقم واتساب — يُطبَّق على كل صفحات المنتجات عند النشر
واتساب
عند إلغاء الإظهار يبقى رقم واتساب مستعملاً في رسالة تأكيد الطلب عبر زر «تأكيد الطلب» العادي.

العروض

SEO (اختياري)
تُستخدم هذه الحقول لتحسين ظهور المنتج في نتائج البحث ومعاينة الرابط عند مشاركته على فيسبوك/واتساب/تويتر (Open Graph). صورة أول عنصر في قائمة الصور أدناه تُستخدم تلقائياً كصورة المعاينة.
🏠 صورة الغلاف (الصفحة الرئيسية والبطاقات)
هذه هي الصورة الوحيدة التي تظهر في بطاقة المنتج بالصفحة الرئيسية، «الأكثر مبيعاً»، وسلة الشراء — منفصلة تماماً عن صور صفحة المنتج أدناه
إذا تُركت فارغة، تُستعمل أول صورة من معرض صفحة المنتج تلقائياً كغلاف احتياطي
🖼️ صور صفحة المنتج (المعرض)
هذه الصور تظهر فقط داخل صفحة المنتج الخاصة (الصورة الكبيرة والمصغّرات) — لا علاقة لها بصورة الغلاف أعلاه
مثال: assets/img/anti-acne/presentation/anti-acne 01.webp
تُجلب الصورة من الرابط وتُرفع مباشرة إلى مجلد صور هذا المنتج على GitHub (assets/img/<المعرف>/)، ثم تُضاف تلقائياً لقائمة الصور أعلاه — يتطلب ضبط GitHub من زر ⚙️ في معاينة الصفحة، وأن يسمح مصدر الصورة بالوصول من متصفح (CORS)
اختر صورة محفوظة على جهازك — تُحوَّل تلقائياً إلى webp وتُرفع لمجلد صور هذا المنتج، دون الحاجة لرابط إنترنت
