# README الواجهة الرئيسية للمنصة — تكليف لـ ChatGPT (التصميم والصور والقالب)

> **تقسيم العمل:**
> - **أنت (ChatGPT)** تنشئ **الصور** و**القالب** (تصميم الصفحة الرئيسية كاملاً بـHTML وCSS ثابتين، جاهزاً بصرياً ومرتّباً).
> - **أنا (Claude)** أكتب **الكود** بعدك: السلوك (JavaScript)، الترجمة بثلاث لغات، التفاعلات، ربط النماذج، الأداء، والتكامل مع المنصة.
>
> لذلك **لا تكتب منطقاً برمجياً** (لا JavaScript)، بل سلّمني قالباً يحوي كل عناصر الواجهة وحالاتها ومعرّفات واضحة أبني عليها (القسم 8). هذا الملف هو المرجع الكامل: ما هي المنصة، لمن، هويتها، محتواها الحقيقي، ما يجوز قوله وما لا يجوز، ثم قائمة الصور المطلوبة بمواصفاتها وأوامر توليدها، ثم مواصفات القالب وطريقة التسليم.

**الهدف:** صفحة رئيسية تسويقية للمنصة (موقع تعريفي بصفحة واحدة قابلة للتوسّع لصفحات فرعية) موجَّهة إلى: تجّار المنتجات الفيزيائية، وبائعي المنتجات الرقمية، ومصمّمي الصور والمواقع المحترفين، وصنّاع المحتوى وأصحاب العلامات التجارية.

## 1) ما هي المنصة؟

منصة **SaaS لإدارة التجارة الإلكترونية وصناعة المحتوى البصري** في مكان واحد: يفتح التاجر لوحة تحكم واحدة، ينشئ موقعه ومتجره وصفحات البيع، يستقبل الطلبات ويؤكدها ويشحنها ويحصّل ماله ويحسب ربحه الحقيقي، ويصمّم صوره وإعلاناته وفيديوهاته ويدير حملاته — دون أن يتنقل بين عشرة تطبيقات.

**أركانها الستة:**
1. **متجر وصفحات بيع** — منشئ صفحات مرئي (سحب وإفلات)، 27 قالباً جاهزاً بحسب المجال، نموذج طلب بصفحة واحدة، سلة، عروض إضافية.
2. **تشغيل الطلبات** — مركز اتصال لتأكيد الطلبات، مخزون ومستودعات، شركات توصيل، مرتجعات، جرد، تجهيز وطباعة بوالص.
3. **المال والربح** — ربح حقيقي بعد التوصيل والمرتجعات والإعلانات، محفظة بضمان (Escrow)، دفع إلكتروني وتحويلات، خدمات تسويق جاهزة.
4. **ستوديو الصور والتصميم** — 15 أداة رئيسية (وأدوات مساندة) لتحرير صور المنتجات وتوليد المشاهد والفيديو والشعار والهوية البصرية ومعالجة مئات الصور دفعة واحدة.
5. **أسواق ونظام بيئي** — سوق توريد (دروبشيبينغ/جملة)، شبكة خبراء مستقلين (مصممون، مشترو إعلانات، مؤكّدات، موزّعون، صنّاع UGC)، متجر تطبيقات لمطوّرين مستقلين.
6. **API مفتوح للمطوّرين** — أحداث وWebhooks موقَّعة، OAuth، تكاملات (Meta/TikTok/Snapchat، واتساب، Google Sheets)، توثيق OpenAPI.

**اللغات والاتجاه:** الواجهة الأساسية عربية (RTL)، مع إمكانية الفرنسية والإنجليزية. المنصة **عالمية الطموح**: لا تُحصَر في سوق واحد ولا في نشاط واحد (عسل/تجميل مثلاً)؛ أمثلة الأسعار والتوصيل الجزائرية تُذكر فقط كمثال على عمق التكامل المحلي.

**اسم المنصة:** *لم يُحسم بعد.* استعمل المتغيّر `{{PLATFORM_NAME}}` في كل مكان، وشعاراً مؤقتاً نصياً. (المرشح الأقرب حالياً: «Tesave» — لا تعتمده نهائياً.)

## 2) الجمهور المستهدف — أربع شرائح

> لكل شريحة: **الرسالة** (جملة واحدة)، **الألم الذي نحلّه**، **ما تراه في المنصة**. يجب أن يعرض الموقع مدخلاً واضحاً لكل شريحة (تبويبات أو بطاقات أو أقسام)، مع مقطع مشترك للجميع.

### 2.1 تجّار المنتجات الفيزيائية (دروبشيبينغ، متاجر محلية، علامات صغيرة)
- **الرسالة:** «من إعلان الفيسبوك إلى تسليم الطرد وربحك الحقيقي — في لوحة واحدة.»
- **الألم:** طلبات الدفع عند الاستلام تضيع بين واتساب وجداول البيانات؛ نسب مرتجعات عالية؛ لا يعرف التاجر ربحه الفعلي بعد رسوم التوصيل والمرتجعات والإعلانات.
- **ما يراه:** مركز اتصال لتأكيد الطلبات بالدور مع أهداف يومية للمؤكّدات، توجيه تلقائي لشركة التوصيل الأنسب حسب المنطقة والأداء، بوالص مجمّعة وماسح باركود، مخزون متعدد المستودعات مع إرجاع تلقائي للمرتجع، قائمة سوداء للزبائن المشكوك فيهم، سلال متروكة، «الربح الحقيقي» مع إنفاق Meta/TikTok، أكواد خصم وعروض Bump/Upsell، سوق توريد للبيع بعمولة دون مخزون.

### 2.2 بائعو المنتجات الرقمية (اشتراكات، حسابات، مفاتيح تفعيل، ملفات، دورات)
- **الرسالة:** «بع مفاتيحك وملفاتك واشتراكاتك وتسلَّم الدفع واسلِّم المنتج تلقائياً — بلا توصيل ولا انتظار.»
- **الألم:** التسليم اليدوي بالواتساب، التحقق من تحويلات الدفع، نفاد مخزون المفاتيح دون تنبيه، لا رابط تنزيل آمن.
- **ما يراه:** متجر بنوع «رقمي» بلا ولايات ولا توصيل، مخزن مفاتيح مشفّر بمنع التكرار، تسليم تلقائي بعد تأكيد الدفع (بريد أو واتساب)، روابط تنزيل محدودة المدة والعدد، دفع بطاقة (Chargily) أو BaridiMob/CCP بإثبات تحويل يوافق عليه التاجر بنقرة، تنويعات (شهر/3 أشهر/سنة) بمخزون مستقل، تنبيهات نفاد المخزون.

### 2.3 مصمّمو الصور والمواقع المحترفون (فريلانسرز، استوديوهات، وكالات)
- **الرسالة:** «ستوديو كامل لتحرير صور المنتجات وتصميم الصفحات — اشتغل أسرع، سلِّم لعملائك أكثر، واربح من خبرتك.»
- **الألم:** تكرار نزع الخلفيات وتوحيد المقاسات؛ تسليم مئات الصور؛ أدوات متفرقة واشتراكات متعددة؛ صعوبة إيجاد عملاء.
- **ما يراه:** 15 أداة صور رئيسية (إزالة الخلفية، التقاط العناصر، حذف العناصر، تلوين، تغيير المقاس والتوسيع، مشاهد المنتج، تصوير المنتج، النموذج والتجربة الافتراضية، تحريك الصورة، شعار وهوية بصرية، معالجة دفعات، كتالوج) وأدوات مساندة، معالجة دفعات حتى 250 صورة بقالب معالجة موحّد، منشئ صفحات مرئي بقوالب ونسخ قوالب من مواقع أخرى، **شبكة الخبراء** (ملف عام وتقييمات وواتساب مباشر من التاجر)، **متجر التطبيقات** لبيع إضافاتهم وتقاسم الإيراد، وبيع خدمات للتجار داخل المنصة.

### 2.4 صنّاع المحتوى وأصحاب العلامات التجارية
- **الرسالة:** «هوية علامتك — ألوانها وخطها وشعارها — تُطبَّق على كل صورة وفيديو ومنشور وصفحة تلقائياً.»
- **الألم:** اتساق العلامة عبر المنصات، تكلفة التصميم، النشر المنتظم على السوشيال.
- **ما يراه:** الهوية البصرية المحفوظة (ألوان/خط/شعار) تُطبَّق على كل المخرجات، منشئ الشعار (نصي مجاني أو بالذكاء)، مولّد الصور والإعلانات بمقاسات كل المنصات والنشر المتعدد بنقرة، فيديو إعلاني من صورة بقوالب ستوري/ريلز، سوشيال: جدولة فيسبوك/إنستغرام بقوالب نصوص وتوليد نص ذكي، مدوّنة وSEO، مكتبة أصول (صور وأيقونات وفيديو بلا علامات مائية) وآلاف الملصقات، موقع متكامل بنطاق خاص.

## 3) الهوية البصرية (إلزامية)

### 3.1 الألوان
| الدور | القيمة | ملاحظة |
|---|---|---|
| خلفية داكنة أساسية | `#06130e` (و`#06120d`) | سطح الصفحة |
| خلفية ثانوية داكنة | `#0b2018` / `#0b1d15` | أقسام داكنة متناوبة |
| **اللون المميّز (Mint/ليموني)** | **`#c6fe17`** (RGB `198,254,23`) | الأزرار الأساسية، الروابط، الأيقونات، الشارات، التوهج الخفيف |
| أخضر المنصة العميق | `#173f35` | حدود، خلفيات أزرار على الأقسام الفاتحة |
| أخضر ثانوي | `#22c55e` / `#4ade80` | تدرجات الأزرار والمخططات |
| نص على الداكن | `#f3f8f4` (أساسي) · `#b8c9be` (ثانوي) | |
| قسم فاتح | خلفية `#f6f8f5` / `#ffffff` ونص `#10241b` وثانوي `#5a6b61` | أقسام التناوب |
| ألوان الحالات | برتقالي `#ffd45e` تنبيه · وردي-أحمر `#ff5d82` خطأ/حذف · أزرق `#5aa8ff` معلومة · سماوي `#3be6ff` · بنفسجي `#b79bff` | للمخططات والشارات فقط وبقدر قليل |

**قواعد:** الطابع العام **زجاج داكن أخضر** (Dark Glass): أسطح شبه شفافة بحدود رفيعة `rgba(255,255,255,.14)` وتمويه خلفية، وتدرجات خضراء هادئة في الزوايا. الليموني **للتمييز فقط** (لا تملأ مساحات كبيرة به). تناوب الأقسام الداكنة والفاتحة مسموح (انظر 3.5).

### 3.2 الخط
- **Cairo** (Google Fonts) بالأوزان 400/700/800/900 للعربية واللاتينية. بديل: `'Segoe UI', Tahoma, sans-serif`.
- العناوين الكبيرة وزن 900، العناوين الفرعية 800، النص 400–700. حجم العنوان الرئيسي `clamp(2rem, 5vw, 3.2rem)`، سطر النص 1.7–1.8.
- الاتجاه `dir="rtl"` و`lang="ar"` افتراضياً، مع دعم `ltr` للفرنسية/الإنجليزية عبر `dir` على الجذر.

### 3.3 المكوّنات
- **الأزرار — قاعدة ثابتة:** *زجاج شفاف منتفخ قليلاً بنص أبيض* دون لون صلب: أخضر/ليموني للأساسي، رمادي زجاجي للثانوي، برتقالي للتنبيه، أحمر للحذف. «منتفخ» = لمعة علوية داخلية + ظل داخلي سفلي + ظل خارجي خفيف + `backdrop-filter: blur`. التفاعل عند المرور = تلوين أقوى + `translateY(-2px)` **دون توهج مبالغ**. (انظر 3.5)
- **الشارات (pill):** نص ليموني صغير بحدّ ليموني شفاف وخلفية `rgba(198,254,23,.08)`.
- **البطاقات:** زوايا 16–20px، حدّ رفيع، ظل ناعم؛ على الداكن سطح زجاجي، على الفاتح أبيض بحدّ `#e3e9e3`.
- **الأيقونات:** خطّية (stroke 2، زوايا مستديرة)؛ **ممنوع الإيموجي** في الواجهة. استعمل SVG خطياً (Lucide/Tabler مسموحان — ترخيص MIT).
- **الحركة:** خفيفة وهادئة (ظهور عند التمرير، تحويم)، وتحترم `prefers-reduced-motion`.
- **شريط التمرير:** رفيع.

### 3.4 قواعد الصور (من صاحب المنصة — صارمة)
- بلا علامات مائية أو شعارات مواقع أو علامات تجارية ظاهرة.
- **لا امرأة بلا خمار** ولا جزء عارٍ من الجسم عدا الوجه واليدين. (يمكن عرض رجال بلباس كامل ونساء بخمار ولباس محتشم، أو الاكتفاء بالمنتجات والمشاهد والمانيكان.)
- لا نصوص مدمجة داخل الصور (النص يُكتب HTML حتى يُترجَم).
- صور المنتجات: خلفيات واقعية دافئة أو استوديو نظيف؛ ألوان المنتجات الطبيعية تتناغم مع الأخضر الداكن.

## 4) هيكل الصفحة الرئيسية المطلوب

> الترتيب مقترح؛ يجوز تحسينه بشرط بقاء كل الأقسام. كل قسم بعنوان + جملة + عناصر. **لا تخترع أرقاماً أو شهادات أو شعارات عملاء أو أسعاراً** (القسم 6).

1. **شريط علوي ثابت:** الشعار `{{PLATFORM_NAME}}` — روابط (المزايا، الأدوات، الشرائح، الأسئلة) — زر ثانوي «تسجيل الدخول» — زر أساسي «ابدأ مجاناً» (أو «اطلب عرضاً» حتى تُحسم الباقات) — مبدّل اللغة (ع / Fr / En).
2. **الهيرو:** عنوان قوي بنفَس «كل أدواتك — متجر، طلبات، شحن، ربح، وتصميم — في منصة واحدة»؛ فقرة؛ زرّان؛ ثلاث نقاط ثقة صادقة (مثلاً: «بالعربية RTL كاملة»، «بلا تثبيت»، «أدوات صور مجانية»)؛ **مشهد بصري كبير** (لقطة لوحة تحكم مصمّمة بالـHTML/CSS أو ولّد صورة لها) محاطاً بصور المنتجات العائمة من القسم 7 (`hero-02-products-floating`).
3. **اختر طريقك (الشرائح الأربع):** بطاقات/تبويبات كبيرة، لكل منها صورة، رسالة، 3–4 نقاط، رابط «اكتشف».
4. **كيف تعمل؟ (3–4 خطوات):** أنشئ متجرك ← أضف منتجاتك وصفحاتك ← استقبل الطلبات وأكّدها وأرسلها ← قِس ربحك الحقيقي وكبّر.
5. **لوحة التحكم في لمحة:** عرض بصري لمحاكاة اللوحة الداكنة (بطاقات إحصاء ليمونية، مخطط، جدول طلبات بشارات حالة) مع تعليقات توضيحية على 5–6 وحدات.
6. **ستوديو الصور والتصميم:** عرض الأدوات الـ15 الرئيسية ببطاقات (من جدول 5.8: الاسم وسطر وشارة «مجانية/ذكاء» وأيقونتها) مع شريط قبل/بعد من أزواج `studio-0x`، مع شريط قبل/بعد تفاعلي، وأزرار «جرّب».
7. **متجر ومنشئ صفحات وقوالب:** معرض 27 قالباً بحسب المجال (صور `store-0x-*-mock`) مع مرشّحات (أزياء، تجميل، عسل وأعشاب، مكملات، إلكترونيات، رقمي، مجوهرات، ساعات…).
8. **التشغيل والتوصيل والمال (للفيزيائي):** شبكة مزايا: مركز الاتصال، التوجيه الذكي، البوالص، المخزون والمرتجعات، الربح الحقيقي، المحفظة والضمان.
9. **المنتجات الرقمية:** قسم مستقل بمنطق «بع ← ادفع ← تسلَّم آلياً» مع مخطط مبسّط للتدفق.
10. **للمحترفين وصنّاع المحتوى:** شبكة الخبراء، متجر التطبيقات (للمطوّرين)، الهوية البصرية، سوشيال وفيديو، API وWebhooks.
11. **المنظومة المفتوحة (للمطوّرين):** بطاقة API/تكاملات/OAuth مع مقتطف كود وهمي واضح أنه مثال.
12. **لماذا نحن (التمايز):** عربية RTL أصيلة وتكامل محلي، كل شيء في لوحة واحدة، أدوات مجانية بلا ذكاء + ذكاء اختياري بتكلفة شفافة، ملكية بياناتك، أمان (2FA وأدوار وسجلّ نشاط).
13. **الباقات:** هيكل بطاقات **بلا أسعار** («قريباً/تواصل معنا») إلى أن تُحدَّد؛ ضع مكان السعر `{{PRICE}}`.
14. **أسئلة شائعة (8–10):** بإجابات صادقة (القسم 6).
15. **دعوة أخيرة + تذييل:** نموذج بريد/واتساب، روابط (المنتج، الأدوات، الموارد، قانوني)، حسابات التواصل `{{SOCIAL}}`.

### 5.1 لوحة التحكم (أقسامها حسب المجموعات)

لوحة داكنة زجاجية (ومظهر فاتح اختياري) بشريط جانبي وبحث سريع و«اسألني» (مساعد مدمج) وأوامر صوتية. المجموعات الخمس:

**المتجر (e-commerce):** الطلبات (بحث وفلاتر وعروض محفوظة وتحديد جماعي وإجراءات جماعية وفواتير A4 وبوالص A6 بباركود) · الطلبات المسجلة (طرود شركة التوصيل بحالتها الحقيقية) · **مركز الاتصال** · تجهيز الطلبات (دور أمين المخزن: قائمة جمع ووصل تجهيز) · المخزون والأرباح · المدفوعات · تكلفة المنتجات (من سعر شراء أو من وصفة مواد أولية) · **الربح الحقيقي** · المحفظة · التوجيه والبوردرو · شركات التوصيل · رسوم التوصيل (مناطق + استثناءات بلديات) · أكواد الخصم + عروض تلقائية · العروض الإضافية (Bump وUpsell) · العملاء (شرائح، VIP، وسوم) · المرتجعات · إعادة الشراء (رسائل واتساب) · الجرد والمخزون (حدود دنيا ومستودعات) · البكسلات (فيسبوك/تيك توك/جوجل) · السوشيال والإعلانات · التقارير · الزبائن الأوفياء · القائمة السوداء · شبكة الخبراء · خدمات التسويق · سوق التوريد · المنتجات الرقمية · متجر التطبيقات · استوديو التطبيقات (للمطوّرين) · مركز المتاجر (طلبات Shopify وWooCommerce وجداول Google في لوحة واحدة).

### 5.3 الطلبات والتوصيل
- **تأكيد الطلبات (CRM):** طابور بالدور، نتائج اتصال (تأكيد، لم يُجب 1–3، لاحقاً/غداً، رقم خاطئ، إلغاء بسبب)، تعديل العنوان مع التأكيد، قفل الطلب أثناء الاتصال، **أهداف يومية** لكل موظفة، توزيع الطلبات بين الموظفات (حصص/حسب الشركة/حسب الولاية/يدوي)، تنبيه تأخر، ترتيب الفريق، زمن أول استجابة.
- **شركات التوصيل:** ربط حسابات عبر مفاتيح API؛ ياليدين (مُتحقَّق منه فعلياً: إنشاء/تتبع/بوليصة/إلغاء) وZR Express وMaystro وNOEST وعائلة Ecotrack (تجريبية، تنتظر حسابات حقيقية)؛ أسعار تلقائية بتعريفة الشركة وإضافات البلديات؛ **توجيه تلقائي** بحسب المنطقة وأفضل نسبة تسليم؛ **إعادة توجيه** لشركة بديلة عند الرفض؛ إرسال جماعي وطباعة بوالص الشركة الأصلية؛ **محطة مسح** بالباركود وكشف تسليم؛ مزامنة الحالات تلقائياً؛ **فحص المفاتيح** استباقياً.
- **بوابة شحن مستقلة (API)** لتجميع الشركات خلف واجهة واحدة (REST + Webhooks موقَّعة) — تُباع كخدمة لمطوّرين خارج المنصة.
- **المخزون:** مستودعات متعددة وتوجيه الخصم حسب الولاية، حدود دنيا وتنبيهات، **إرجاع تلقائي للمرتجع** عند وصوله للبائع، جرد بسجل حركة، ربط المخزون بالطلبات (يعرف أي طلب خارج المخزون)، سلة مهملات للطلبات.
- **المرتجعات:** طلب/موافقة/استلام/استرداد أو استبدال مع مهلة وتخزين مرتجع سليم أو تالف.
- **الجداول:** لكل جدول تحديد وقائمة Action (طباعة، CSV، Excel).

### 5.4 المال والربح
- **الربح الحقيقي:** المحصَّل فعلاً من الطرود المسلَّمة − كلفة البضاعة − التوصيل − التغليف − خسارة المرتجعات − المستردّات − **الإعلان الفعلي من Meta وTikTok** − مصاريف ثابتة؛ مؤشرات (نسبة التسليم، CPA وROAS الحقيقيان)، جدول حملات وولايات، **ربط حساب فيسبوك الإعلاني بنقرة** (OAuth) لسحب الإنفاق تلقائياً.
- **تسوية شركة التوصيل:** مطابقة كشف الدفع، حساب الرسوم الحقيقية (COD، تأمين، إرجاع).
- **دورة حياة الحملة:** إيقاف الحملة وأرشفتها وربطها بالأرباح والمخزون وتنبيه نفاد المخزون أثناء حملة نشطة.
- **المحفظة:** رصيدك على المنصة (متاح · ضمان · قيد السحب · رصيد إعلانات بالدولار) بدفتر **قيد مزدوج** غير قابل للتعديل؛ ضمان Escrow يُحرَّر عند التسليم؛ طلبات سحب (CCP، BaridiMob، بنك، RedotPay، PayPal)؛ شراء رصيد إعلانات بالدولار.
- **الدفع:** رابط دفع إلكتروني بالبطاقة (Chargily Pay)، حوالات BaridiMob/CCP بإثبات صورة وموافقة يدوية، شحن المحفظة.
- **خدمات التسويق (White Label):** اشترِ حساباً إعلانياً (TikTok/Meta) جاهزاً بالدينار من محفظتك؛ المبلغ يُحجز ضماناً ويصلك رابط الدعوة عند التسليم.

مخزن مفاتيح وحسابات مشفّر (بصمة تمنع التكرار) · تسليم تلقائي عند `payment.confirmed` · ملفات برابط محدود · بريد أو واتساب · طرق دفع: بطاقة/BaridiMob/CCP · إثبات تحويل بصورة (JPEG/PNG/WebP) وموافقة بنقرة · تنويعات بمخزون مستقل · تنبيهات المخزون المنخفض · لوحة «الرئيسية الرقمية» · لا ولايات ولا توصيل.

### 5.6 الأسواق والنظام البيئي
- **سوق التوريد:** مورّد يُدرج منتجاً بسعر جملة وعمولة؛ تاجر يستورده بنقرة ويبيعه بسعره؛ **عمولة تُحجز من رصيد المورّد وتُحرَّر عند التسليم** (حماية للطرفين)؛ بوابة للمورّدين الخارجيين وأنواع «جملة/تجزئة».
- **شبكة الخبراء:** دليل مستقلين بملف عام وتقييمات موثّقة وشارة «موثّق» وبحث بتخصص وولاية وسعر؛ تواصل واتساب مباشر؛ مساحة المستقل بمفتاح سرّي.
- **متجر التطبيقات:** تثبيت تطبيقات مطوّرين بصلاحيات مغلقة يوافق عليها التاجر، **بيانات الزبائن مقنَّعة افتراضياً**، OAuth 2.0، اشتراكات وتقاسم إيراد (عمولة المنصة 20% افتراضياً)، تقييمات واسترداد 7 أيام؛ **استوديو المطوّر** لإنشاء التطبيقات ومتابعة التسليمات والإيرادات.
- **مركز المتاجر:** تجميع طلبات Shopify وWooCommerce وجداول Google من كل متاجرك للقراءة والاستيراد.

### 5.8 ستوديو الصور والتصميم — الأدوات الـ15 وطريقة استعمال كل أداة
> **هذا القسم مراجَع ومصحَّح على ما بُني فعلاً في المنصة** (انطلق من دليل أدوات أعدّه صاحب المنصة ثم صُحّحت فيه كل نقطة تخالف سلوك الأداة الحقيقي). استعمله لتصميم **صفحة تعريف لكل أداة** (ما هي، خطواتها، ما تعطيك، حدودها، الفرق عن المشابهة) ولبطاقات الأدوات في الصفحة الرئيسية. **لا تعرض ميزة غير مذكورة هنا، ولا تضف وعوداً.**

**كيف تعمل الأدوات عموماً:**
- تُفتح من محرّر الصفحات: يحدّد التاجر صورة في الصفحة ← تبويب **«تعديل الصورة»** ← يختار الأداة. (معالجة الدفعات وفحص الكتالوج في تبويب **«أدوات الصور»**، ومولّد الصور في وضع «صور إشهارية».)
- **المعاينة مباشرة على الصورة نفسها** في الصفحة، ثم **«تنفيذ»** أو **«إلغاء»**؛ والأصل لا يضيع (تراجع وإعادة متاحان).
- **مجانية** = تعمل داخل متصفح التاجر ولا تغادر الصورة جهازه. **بالذكاء** = تُرسل الصورة إلى خدمة الذكاء الاصطناعي المدمجة (Alyssum API) **بعد أن تُعرض التكلفة التقديرية ويؤكّدها التاجر**، وبسقف إنفاق يحدّده (والمفتاح لا يظهر للزبائن). عند غياب المفتاح تظهر رسالة واضحة ولا تُعرض نتيجة وهمية.
- كل نتيجة بالذكاء قد تغيّر تفاصيل دقيقة (نصوص العبوة، الشعار، النقوش)، **فتحتاج مراجعة بصرية قبل النشر**.

#### 01 — إزالة الخلفية (Suppression de fond) — مجانية
**الهدف:** عزل المنتج (أو الشخص) عن خلفيته وإخراج صورة شفافة PNG.
**الاستعمال:** حدّد الصورة ← «إزالة الخلفية» ← تظهر النتيجة فوق الصورة مباشرة ← «طريقة أخرى» إن لم تعجبك ← «تنفيذ».
**كيف تختار الطريقة:** خلفية متجانسة (مثل استوديو أبيض) ← فصل لوني سريع بلا ذكاء؛ وإلا نماذج تعمل في المتصفح لكشف الموضوع والعمق؛ وللخلفيات المعقدة يمكن (إن توفر مفتاح الذكاء وبعد تأكيد التكلفة) طريقة تعتمد الخدمة الذكية. نسخة مستقلة لصور منفردة (إزالة خلفية + ضغط/WebP + تنزيل) في تبويب «أدوات الصور».
**ما بعد الإزالة:** تبقى الشفافية (PNG)، أو يُوضع المنتج على لون/تدرّج/مشهد من «استوديو المنتج» (#03)، وتُنزَّل الصورة بصيغة PNG أو WebP أو JPEG؛ وللكتالوجات الكبيرة تُطبَّق نفس الخطوة على عشرات الصور دفعة واحدة (#13). **لا تذكر API عاماً لإزالة الخلفية للزبائن** (غير متاح كمنتج منفصل بعد).
**أسلوب صفحة التعريف (مستلهم من صفحة أداة مماثلة لمنصة منافسة، دون نسخ نصوصها):** هيرو بجملة قيمة واحدة وزر «ابدأ من صورة» مع منطقة «أفلت صورة هنا» وصور تجريبية جاهزة · ثلاث خطوات (اختر صورة ← الذكاء يعزل المنتج ← نزّل) · أربع حالات استعمال (منتجات فيزيائية، سرعة الإطلاق على دفعات، صور متسقة للمتجر، مناسبة لمنصات البيع) · شبكة «أدوات أخرى تكمّل عملك» · أسئلة شائعة. **لا تنقل أرقامها الدعائية** (نسب زيادة المبيعات وخفض التكاليف…)؛ هي ادعاءات لجهة أخرى — إن لزمت إحصاءات فاستعمل `{{STAT}}` فارغة حتى تتوفر أرقامنا الحقيقية.
**حدود:** دقة الشعر والعبوات الشفافة والخلفيات المزدحمة تتفاوت؛ تحميل النماذج أول مرة يستغرق وقتاً. **لا تحذف عنصراً من وسط الصورة** (هذه #09) **ولا تنقله** (#15).

#### 02 — مولّد الصور (Générateur d'images) — بالذكاء
**الهدف:** إنشاء صور أصلية من وصف نصي، بنمطين: (أ) **من وصف نصي فقط** بلا صورة مرجعية، (ب) **من صورة منتجك** فيُحفظ المنتج كما هو وتتغير البيئة حوله.
**الاستعمال — من وصف نصي:** «صورة من وصف نصي» ← اكتب وصفاً واضحاً (الموضوع + المكان/الخلفية + الإضاءة + الأسلوب) ← اختر النسبة (1:1، 4:5، 9:16، 16:9) ← تأكيد التكلفة ← النتيجة تُضاف للصفحة أو تُحفظ في المكتبة أو تُنزَّل؛ عدّل الوصف وأعد التوليد حتى تصل لما تريد.
**الاستعمال — من صورة المنتج (وضع «صور إشهارية»):** اختر المنتج ← نوع الصورة (صورة منتج / إشهارية بمقاس منصة: Facebook، Instagram، TikTok، Shorts، YouTube، Google Ads، أو مقاس مخصص) ← النص اختياري (بلا نص / نص يُضاف كطبقات **قابلة للتعديل** في المحرّر / نص من الذكاء) ← الخلفية (مشهد، لون موحّد، شفافة) ← «إنشاء» ← فتح في المحرّر أو حفظ في المكتبة أو تنزيل.
**ماذا تصنع به (للعرض في الصفحة):** مشاهد بأسلوب صور المنتجات دون جلسة تصوير · خلفيات وعناصر بصرية لتركيبها خلف صور المنتجات أو داخل مواد تسويقية · أفكار أولية لرموز وعناصر هوية (للشعار الفعلي استعمل #12) · صور إعلانية جاهزة بمقاسات المنصات.
**حدود:** التكلفة تُؤكَّد قبل كل توليد ولا إعادة محاولة تلقائية؛ التوليد من وصف نصي فقط يعمل مع الاتصال الأول للخدمة الذكية؛ لا نص ولا شعار يُضاف تلقائياً (والنص داخل الصورة المولَّدة غير مضمون الصحة — يُفضَّل إضافته كطبقة)؛ الخلفية الشفافة والألوان الموحّدة تطلبها التعليمات ولا تُضمَن بالبكسل؛ **لا أداة مستقلة لأيقونات الواجهة** (غير مبنية). لا تَعِد بحقوق استعمال تجاري أو ملكية قانونية للصور: اكتب «راجع شروط الخدمة» عبر `{{TERMS_LINK}}` حتى تُحسم الصياغة.
**أسئلة شائعة مقترحة (إجاباتها من الأعلى فقط):** ما هو مولّد الصور؟ · ما أنواع الصور الممكنة؟ · كيف أكتب وصفاً فعّالاً؟ (موضوع واضح + مكان + إضاءة + أسلوب، ثم حسّن وأعد) · هل أنتج صور منتجاتي؟ (نعم من صورة مرجعية) · كم التكلفة؟ (تظهر قبل كل توليد ويحدد التاجر سقفها).

#### 03 — تصوير المنتجات بالذكاء (Photographie de produit IA) — بالذكاء
**الهدف:** تحويل صورة منتج إلى عدة لقطات احترافية دفعة واحدة مع إبقاء المنتج كما هو.
**الاستعمال:** حدّد الصورة ← «تصوير المنتج بالذكاء» ← اختر **حتى 3 مشاهد** من: استوديو أبيض، رخام فاخر، أعشاب وطبيعة، خشب ريفي، مطبخ عصري، حمام وسبا، هدية وتغليف، صيف وشاطئ، أجواء رمضانية، نيون ليلي، انتعاش وماء، لون صارخ بسيط؛ ومشاهد «استخدام يومي»: في اليد، على الطاولة، محمول/ملبوس (بلا وجه وبلباس محتشم)، مكتب، هدية ← موافقة تكلفة واحدة ← بطاقات خيارات تختار منها وتطبّق. (+ «أساليب تصوير ذكية»: 12 أسلوباً.)
**بديل مجاني بلا ذكاء:** «استوديو المنتج» (من تبويب «تعديل الصورة») ينزع الخلفية ويركّب المنتج على لون أو تدرّج أو مشهد جاهز مع ظل ومقاس منصة، ويُطبَّق نفس النمط على كتالوج كامل (#13، #14). اعرضه في الصفحة كخطوة أولى مجانية قبل المشاهد الذكية.
**مسار الصفحة المقترح (مستلهم من مرجع فوتوروم، بلا نقل أرقامه):** (1) صوّر بما لديك — هاتف أو صور موجودة تكفي · (2) عدّل مرة واحدة وطبّق على الكل — إزالة الخلفية، نمط موحّد، ثم دفعات · (3) انشر بالمقاسات التي تحتاجها كل منصة (تصدير بمقاسات متعددة وتنزيل). **لا تذكر دفعاً مباشراً إلى Shopify/Amazon/Etsy أو أي PIM، ولا API لمعالجة الصور للجهات الخارجية؛ غير مبنية.** ما يخص الكتالوج: «فحص جودة الأغلفة» (#14) يشبه فحص الجودة البصري وهو مبني فعلاً؛ أما «تقييم أمانة المنتج» و«وكلاء مرئيين» فغير موجودين. لا تضع قسم شهادات أو أرقام وفورات (`{{STAT}}` `{{TESTIMONIAL}}` فارغة).
**حدود:** قد تتغير تفاصيل العبوة الدقيقة. **الفرق عن #06:** هنا تختار أنت المشاهد وتقارن عدة نتائج؛ في #06 نقرة واحدة بمشهد تلقائي.

#### 04 — النموذج الافتراضي / استوديو الأزياء (Modèle virtuel) — بالذكاء
**الهدف:** عرض قطعة ملابس على عارض افتراضي، أو تجهيز صورتها للمتجر.
**الاستعمال:** حدّد صورة القطعة ← «استوديو أزياء ذكي» ← اختر الوضع: **عارض افتراضي** (مانيكان بلا وجه — الافتراضي — أو رجل، أو امرأة بخمار ولباس محتشم) أو **مانيكان غير مرئي** أو **تصوير مسطح** أو **إزالة التجاعيد** ← الوضعية (أمامي/يمشي/نصف جانبي) ← الخلفية (أبيض، رمادي، شارع ضبابي، داخلي دافئ) ← المقاس ← معاينة مباشرة ← «تنفيذ».
**ما يختلف عن أدوات مماثلة عند منافسين (لا تعرضه كميزة لدينا):** لا معرض عارضين متنوعين بالجنس والعرق والعمر والجسم · لا حفظ عارضين مخصصين لإعادة استعمالهم في مجموعات لاحقة · لا تركيب عدة قطع في إطلالة واحدة · لا دقات مضمونة (2K/4K). الخيارات الفعلية ثلاثة: **مانيكان بلا وجه** (الافتراضي) أو **رجل** أو **امرأة بخمار ولباس محتشم**، وهذا اختيار مقصود يناسب سوقنا ويُذكر كميزة «احتشام وخصوصية» لا كنقص.
**للصفحة:** ثلاث خطوات (ارفع صورة القطعة ← اختر الوضع والوضعية والخلفية ← حدّد المقاس ونزّل) · توضيح الفرق بين الأوضاع الأربعة (عارض، مانيكان غير مرئي، تصوير مسطح، إزالة التجاعيد) · لاستكمال سلسلة العمل: تلوين القطعة (#10) ودفعات (#13). لا أرقام نتائج ولا ادعاء «واقعية كصور الاستوديو» (`{{STAT}}` فارغة). API لهذه الأداة غير متاح للخارج.
**حدود:** **لا معرض نماذج جاهزة ولا رفع صورة نموذج** (هذا في #05)؛ لا يمثل المقاس ولا الملاءمة الفعلية؛ قد تتغير تفاصيل القطعة وتحتاج مراجعة.

#### 05 — التجربة الافتراضية (Essayage virtuel) — بالذكاء
**الهدف:** رؤية قطعة على صورة شخص حقيقي يرفعها التاجر.
**الاستعمال:** حدّد صورة **القطعة** في الصفحة ← «تجربة افتراضية» ← ارفع **صورة الشخص** من جهازك ← تأكيد التكلفة ← معاينة مباشرة (الوجه والجسم والوضعية والخلفية تبقى كما هي) ← «تنفيذ». صورة الشخص تبقى في الذاكرة فقط ولا تُحفظ، إلا إن فعّل «تذكّر صورتي» على جهازه (ويمكنه حذفها بزر).
**ثلاثة استعمالات في أدوات مماثلة، وما نملكه منها:** (1) *جرّب على نفسك* — **متوفر للتاجر فقط** (يرفع صورة شخص ويجرّب قطعه؛ الصورة تبقى للقطع التالية إن فعّل «تذكّر صورتي») · (2) *جرّب على عارض* — متوفر عبر **استوديو الأزياء** (#04) · (3) *تجربة الزبون على صفحة المنتج بزر «جرّب» وواجهة برمجية* — **غير متوفرة**: تتطلب نقطة خادمية وحدود استعمال ورصيداً وسياسة خصوصية لصور الزبائن (مخطَّطة، لا تعرضها كميزة). **لا تعرض زر «جرّب» لزوّار المتجر في الصفحة ولا API للتجربة، ولا مدة نتيجة محددة (مثل ثوانٍ معدودة) ولا ادعاء خفض المرتجعات.** ضع للأمر شارة «قريباً» فقط إن رغبت.
**إرشادات صورة الشخص (يمكن ذكرها):** صورة واضحة أمامية تظهر فيها منطقة القطعة، وهاتف عادي يكفي.
**حدود:** **أداة للتاجر داخل المحرّر**؛ تجربة الزبون على صفحة المنتج **غير متوفرة بعد**. لا وعد بمقاس أو واقعية كاملة. **الفرق عن #04:** تلك عارض افتراضي جاهز، وهذه صورة شخص يختارها المستخدم.

#### 06 — وضع المنتج في مشهد (Mise en scène du produit) — بالذكاء
**الهدف:** وضع المنتج بنقرة واحدة في مشهد أسلوب حياة احترافي مناسب لنوعه (عطر بين الزهور، منتج عناية في حمام أنيق…).
**الاستعمال:** حدّد الصورة ← «مشهد ذكي للمنتج» ← تأكيد التكلفة ← يُستبدل مشهد الصورة (يمكن التراجع).
**للصفحة (مستلهمة من مرجع مماثل):** الفكرة «شاهد منتجك في الاستعمال اليومي» — الأنسب للسلع الصلبة والإكسسوارات كالحقائب والمجوهرات والأحذية · ثلاث خطوات (ارفع/حدّد صورة المنتج ← نقرة واحدة ← راجع النتيجة ونزّل) · فائدتان: سياق واقعي يسهّل تخيّل المنتج، وبلا جلسة تصوير. **الفرق عن أداة المنافس التي ألهمت هذا الوصف:** عندنا نتيجة واحدة تستبدل المشهد وتقبل التراجع (لا خياران تلقائيان)، والتنزيل بصيغ WebP/PNG/JPEG. لا تذكر «خيارين» ولا «تجربة مجانية»، ولا أرقام نتائج (`{{STAT}}` فارغة).
**حدود:** المشهد يُختار تلقائياً (لاختيار المشاهد بنفسك استعمل #03)؛ قد تختلف تفاصيل المنتج.

#### 07 — مولّد الفيديو (Générateur de vidéo) — حالتان: مجانية متوفرة + بالذكاء مخطَّطة
**الهدف:** تحويل صورة منتج إلى **فيديو قصير** جاهز للإعلان.
**الوضع المخطَّط (بالذكاء، عبر API فيديو خارجي — لم يُدمج بعد):** يرفع التاجر/يحدّد صورة، ويكتب **وصفاً نصياً للحركة** (برومبت: «الكاميرا تقترب ببطء من العبوة والبخار يتصاعد…»)، ثم يؤكد التكلفة ويولَّد فيديو قصير. المدة والنسبة والدقة والسعر **تحدّدها الخدمة التي ستُعتمد ولم تُحسم بعد** — لا تُكتب أرقامها في الصفحة؛ استعمل `{{VIDEO_SPECS}}` مكانها. يتبع قاعدة أدوات الذكاء: تأكيد تكلفة، سقف إنفاق، لا نتيجة وهمية عند غياب المفتاح، ومراجعة بصرية قبل النشر.
**الوضع المتوفر الآن (مجاني، داخل المتصفح — «تحريك الصورة»):** حدّد الصورة ← «فيديو من الصورة» ← اختر قالباً: **ستوري إعلان 9:16، عرض خصم، فاخر هادئ، ريلز ديناميكي، واجهة عريضة 16:9، منشور مربع** ← عنوان وسعر وزر دعوة اختيارية بألوان وخط هويتك ← يُسجَّل الفيديو (WebM أو MP4 بحسب المتصفح) ← تنزيل.
**حدود المتوفر الآن:** الصورة نفسها تتحرك (تقريب/تحريك/نبض) وليست توليداً؛ بلا صوت؛ لا يُرفع للمكتبة تلقائياً.
**في الصفحة:** اعرض الأداة كـ«فيديو من صورة المنتج» ببطاقتين: «تحريك سريع مجاني» (متوفر) و«فيديو بالذكاء من وصف نصي» بشارة **«قريباً»**. لا تعرض أمثلة فيديو مولَّدة لم تُنتج فعلاً، ولا مدة أو دقة محددة.

#### 08 — تغيير المقاس والتوسيع وتحسين الجودة (Redimensionner et agrandir)
**الهدف:** ثلاث أدوات متجاورة:
1. **تغيير المقاس — مجاني:** اختر مقاس منصة جاهزاً أو عرضاً وارتفاعاً مخصصين، فيُملأ ما حول الصورة بامتداد مموّه لتصل إلى البكسلات المطلوبة بدقة.
2. **توسيع الخلفية — بالذكاء:** اسحب إطاراً للخارج (حتى 150% في كل جهة) أو اختر نسبة ← «أنشئ خيارين» (تكلفة واحدة) ← اختر أحدهما؛ تُلصق صورتك الأصلية فوق النتيجة بحافة ناعمة فلا يُمَسّ المنتج.
3. **تحسين الجودة — مجاني:** تكبير ×2 أو ×3 أو ×4 أو لعرض محدد، مع حدّة وتقليل ضجيج وتحسين ألوان تلقائي.
**حدود:** **التكبير لا يخترع تفاصيل** (الأصل المنخفض يبقى أنعم لا أوضح)؛ التوسيع يولّد الامتداد فقط؛ سقف ناتج التكبير 24 ميغابكسل (8 على الهاتف).

#### 09 — حذف العناصر (Supprimer des objets) — مجانية
**الهدف:** حذف شيء غير مرغوب من الصورة وإعادة بناء مكانه.
**الاستعمال:** حدّد الصورة ← «ممحاة ذكية بالفرشاة» ← ارسم فوق العنصر بفرشاة بحجم تضبطه ← معاينة ← «تنفيذ» أو «إلغاء» (وتكرر إن بقي أثر).
**حدود:** يعمل بنموذج داخل المتصفح مع ترميم احتياطي؛ الخلفيات المعقدة والأنماط الدقيقة قد تترك آثاراً. **لا تنقل العنصر** (#15) **ولا تعزل الموضوع** (#01).

#### 10 — تلوين الملابس والأشياء (Recolorer) — مجانية وبالذكاء
**الهدف:** تغيير لون جزء من الصورة مع بقاء الظلال والطيّات والملمس.
**الاستعمال:** (أ) **مجاناً** من «لمسات وتصحيح»: انقر على المنطقة واختر اللون. (ب) **بالذكاء** من «تلوين الملابس»: اكتب ما تريد تلوينه (أو اتركه للقطعة الرئيسية) ← اختر **حتى 4 ألوان** من لوحة (أحمر، كحلي، أخضر زيتي، أسود، بيج، وردي، بنفسجي، ذهبي، أبيض، بني) أو لوناً مخصصاً ← تأكيد التكلفة ← يُولَّد خيار لكل لون ← اختر وطبّق.
**حدود:** ألوان الشاشة قد تخالف لون المنتج الحقيقي؛ لا ادعاء بمطابقة الطباعة؛ ألوان الذكاء تقريبية لا بكسلاً ببكسل.

#### 11 — الهوية البصرية (Identité visuelle) — مجانية
**الهدف:** حفظ هوية علامتك وتطبيقها على صورك بتناسق.
**الاستعمال:** «الهوية البصرية» ← اسم العلامة + **خمسة ألوان** (أساسي، ثانوي، خلفية، نص، تمييز) + خط من القائمة + شعار؛ زر لاستيراد ألوان الموقع وخطه واسمه ← تطبيق إطار/خلفية بألوان الهوية وختم الشعار وشريط اسم العلامة بمعاينة حيّة ← «تنفيذ». تتزامن بين أجهزة المالك.
**حدود:** **هوية واحدة** (لا هويات متعددة)؛ لا رفع ملفات خطوط مخصصة؛ لا تُشارك مع أعضاء الفريق؛ لا تغيّر ألوان الصفحة وخطوطها تلقائياً؛ **ليست مولّد شعار** (#12).

#### 12 — منشئ الشعارات (Créateur de logo) — مجانية وبالذكاء
**الهدف:** أفكار شعار أولية ثم اعتماده للعلامة.
**الاستعمال:** اكتب اسم العلامة (والمجال للذكاء) ← (١) **شعار نصي مجاني** بأربعة أنماط: شارة دائرية، مستطيل مدوّر، نص بخط تحتي، مونوغرام، بألوان وخط هويتك (وخلفية فاتحة أو بلون العلامة) ← أو (٢) **«ولّد شعاراً» بالذكاء** (تأكيد تكلفة) ← «اعتمده شعاراً للعلامة» أو «أضفه للصفحة».
**حدود:** **ليس شعاراً حصرياً ولا مسجّلاً قانونياً** وعلى المستخدم التحقق من التشابه مع علامات أخرى؛ الناتج صورة نقطية **لا SVG متجهياً**؛ الشعار بالذكاء قد يختلف في كل مرة.

#### 13 — المعالجة الجماعية (Traitement par lots) — مجانية (+ خطوة ذكاء اختيارية)
**الهدف:** تطبيق الإعدادات نفسها على عدة صور دفعة واحدة.
**الاستعمال:** «أدوات الصور» ← «معالجة الدفعات» ← اختر صوراً من جهازك أو صور منتج ← المقاس (أصلي، 1000×1000، 1080×1080، 1080×1350، 1080×1920، 1920×1080، 1200×628، 1200×400، أو مخصص) مع «ملء بقص» أو «احتواء» ولون خلفية ← علامة مائية (نص أو شعار، 9 مواضع، حجم وشفافية) ← الصيغة (WebP/JPEG/PNG) والجودة ← (اختياري) قالب معالجة بنمط المتجر ← (اختياري) **خطوة ذكاء** على كل صورة: تهيئة مشهد، مانيكان غير مرئي، تصوير مسطح، عارض افتراضي، إزالة تجاعيد، تلوين، تعديل بوصف (حتى **250 صورة** بموافقة تكلفة واحدة) ← تشغيل ← تنزيل صور منفردة أو **ZIP**.
**حدود:** تُنفَّذ صورة بعد صورة فالدفعات الكبيرة بطيئة؛ لا إعادة محاولة للفاشلة وحدها بعد؛ لا تُضاف ملفات أثناء التشغيل؛ خطوة الذكاء تتوقف عند غياب المفتاح؛ ليست كل أداة قابلة للتشغيل الجماعي.

#### 14 — كتالوج المنتجات (Catalogue de produits) — مجانية (+ مشهد ذكي اختياري)
**الهدف:** مراجعة جودة أغلفة منتجات متجرك وتوحيدها.
**الاستعمال:** «أدوات الصور» ← فحص جودة الأغلفة: يفحص **الدقة والوضوح والإضاءة وحجم المنتج في الإطار وقصّ الحواف ومخالفة الخلفية/النسبة للأغلبية**، ولكل ملاحظة **حل** مقترح ← حدّد منتجات ← «طبّق نمط المتجر» (نزع خلفية ← تحسين ← تركيب بنمط استوديو المنتج المحفوظ) ← معاينة قبل/بعد ← اعتماد يستبدل الأغلفة (القديمة تبقى في صور المنتج) وينشر مرة واحدة. اختيارياً «مشهد ذكي» لأغلفة محدّدة بموافقة واحدة. يُبرز المنتجات التي بلا غلاف.
**حدود:** **كتالوج صور لا إدارة كتالوج كامل** (لا مخزون ولا أسعار هنا)؛ لا ينشئ صور منتجات من العدم؛ لا يخترع بيانات.
**ملاحظة عن «تقييم صفحة المنتج»:** أدوات مماثلة عند منافسين تقيّم **رابط أي صفحة** في 30 ثانية بأربع فئات (تنوع الصور، جودة الصور، معلومات المنتج، اتساق العلامة) وتقترح الأداة المناسبة لكل نقص. **هذا غير مبني عندنا.** الموجود فقط: «فحص جودة الأغلفة» (هنا) و«فحص المنتجات» في لوحة التحكم (درجة /100 ومشكلات لكل منتج في المتجر نفسه، وليس لرابط خارجي). لا تعرض «قيّم أي صفحة برابط»؛ يمكن ذكر الفحصين فقط.

#### 15 — التقاط العناصر (Capture d'objet) — مجانية
**الهدف:** عزل عنصر داخل الصورة وجعله طبقة تُنقل وتُكبَّر وتُدوَّر، مع ترميم مكانه الأصلي.
**الاستعمال:** حدّد الصورة ← «التقاط العناصر» ← يبدأ التحليل مباشرة داخل المتصفح (تُحمَّل النماذج أول مرة) فتظهر **العناصر الكاملة** المكتشفة (ما قُطع عند حافة الصورة لا يُعرض) ← اختر عنصراً أو عدة عناصر، أو حدّد **مستطيلاً** ليعيد التحليل داخله، أو «تحليل الصورة كاملة» ← «التقاط» ← يصير كل عنصر طبقة يمكن سحبها وتغيير حجمها وتدويرها ويُرمَّم مكانه محلياً ← «تطبيق». (مع مفتاح الذكاء خيار اختيار العنصر بنقرة أو مستطيل بطريقة أدق، بموافقة تكلفة.)
**حدود:** الدقة تتفاوت (الشعر، الشفاف، الخلفيات المعقدة، عدة عناصر متلاصقة)؛ جودة ترميم المكان متفاوتة؛ لا فرشاة تحديد. **الفرق:** تنقل العنصر؛ #01 تعزل الموضوع كله؛ #09 تحذف العنصر.

## 8) القالب المطلوب منك (تصميم HTML/CSS ثابت — بلا JavaScript)

### 8.1 الملفات
```
template/
├─ index.html        ← الصفحة كاملة بكل الأقسام الـ15 (القسم 4)
├─ styles.css        ← كل الأنماط (يبدأ برموز 3.5)
└─ assets/…          ← الصور المولَّدة + icons.svg
```
HTML/CSS خام بلا أطر عمل (بلا Bootstrap/Tailwind)، يعمل بفتح `index.html` مباشرة.

### 8.2 مواصفات التصميم
- **RTL أولاً** (`<html lang="ar" dir="rtl">`)؛ استعمل خصائص منطقية (`margin-inline`, `inset-inline`) كي ينقلب التخطيط تلقائياً في الفرنسية والإنجليزية.
- **متجاوب:** جوال 360px، تابلت 768px، مكتب 1280px+؛ بلا تمرير أفقي؛ شبكات `grid`/`flex` لا قيم ثابتة مكسورة.
- **التباين ≥ 4.5:1**؛ الليموني نصاً على الأبيض ممنوع؛ حالات `:hover` و`:focus-visible` و`:active` لكل زر ورابط وبطاقة؛ `prefers-reduced-motion` يُلغي الحركة.
- **الحركة:** انتقالات CSS فقط (hover، تلاشٍ عند الظهور بفئة `.is-visible` أضيفها أنا بالسكربت). لا حركة مفرطة.
- **الأيقونات:** من `icons.svg` عبر `<svg><use href="assets/icons.svg#name"/></svg>`. لا إيموجي في الواجهة.
- **الأداء:** صور بـ`width`/`height` و`loading="lazy"` (عدا الهيرو `fetchpriority="high"`)، و`<picture>` لو أضفت نسخ صغيرة، وخط Cairo `display=swap`.
- **الأقسام:** نفّذ كل أقسام القسم 4 بالترتيب، بعناوين وجمل وعناصر **حقيقية من القسم 5** (لا لوريم). النصوص بالعربية الفصحى المبسّطة بنبرة واثقة ومباشرة.
- **القالب يُمثّل لوحة التحكم بالـHTML/CSS** (بطاقات إحصاء، مخطط SVG بسيط، جدول طلبات بشارات حالة) لا بصورة، في قسم «لوحة التحكم في لمحة»؛ ويُستعمل `hero-01` للهيرو.

### 8.3 معرّفات للكود (ليسهل عليّ ربط السلوك)
ضع هذه السمات في الأماكن المناسبة (أنا أكتب الـJS لاحقاً):
| العنصر | السمة المطلوبة |
|---|---|
| كل نص قابل للترجمة | `data-i18n="section.key"` ونصه العربي بداخله (مثل `data-i18n="hero.title"`) |
| الأقسام | `id` بالاسم: `hero audiences how panel studio templates ops digital pros api why plans faq cta` |
| روابط التنقل | `href="#id"` لكل قسم |
| مبدّل اللغة | أزرار `data-lang="ar|fr|en"` |
| تبويبات الشرائح الأربع | أزرار `role="tab" data-tab="physical|digital|designers|creators"` ولوحات `role="tabpanel" data-panel="…"` (كلها مرسومة في HTML، غير النشطة `hidden`) |
| شريط قبل/بعد | عنصر `data-compare` فيه صورتان `data-before` و`data-after` ومقبض `data-handle` |
| مرشّحات القوالب | أزرار `data-filter="all|fashion|cosmetics|honey|digital|tech|jewelry"` وبطاقات `data-cat="…"` |
| الأسئلة الشائعة | `<details><summary>` (أو `data-accordion`) |
| النماذج | `<form data-form="signup|contact">` بحقول `name` واضحة، وزر `type="submit"`، ورسالة حالة `data-form-status` |
| الظهور عند التمرير | الفئة `reveal` على العناصر |
| العدّادات (إن وُجدت) | `data-count-to` — **بلا أرقام مخترعة**، استعمل `{{STAT}}` |

### 8.4 عناصر نائبة (لا تخترع)
استعمل حرفياً: `{{PLATFORM_NAME}}` اسم المنصة (غير محسوم) · `{{PRICE}}` · `{{STAT}}` · `{{TESTIMONIAL}}` · `{{SOCIAL}}` · `{{DEMO_URL}}` · `{{TERMS_LINK}}` (رابط الشروط) · `{{VIDEO_SPECS}}` (مواصفات الفيديو بالذكاء، فارغة حتى تُحسم)، وروابط `#signup` و`#login`. الشعار مؤقتاً نصي بخط Cairo 900 مع رمز بسيط.
